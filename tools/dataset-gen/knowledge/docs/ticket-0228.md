# 取数需求单 REQ-2025-0228

## 需求

会员中心在 2025-09-30 提出取数，关注 2025-01 的总停留秒数（`stay_seconds`），希望按商品 SKU 粒度、日度口径了解各 SKU 的访问停留情况，不设筛选条件。本单编号 REQ-2025-0228，处理人商品数据组。会员中心想从停留时长切入，判断哪些 SKU 更吸引用户驻足。

## 结论

`dws_traffic_sku_visit_1d` 即 DWS-商品SKU 粒度访问汇总（日）对应本次取数，取 `stat_date`、`sku_id`、`pv`、`uv`、`stay_seconds`，报告期 `stat_date` 取 2025-01。

分析时有个加和细节要留意：`stay_seconds` 可跨行相加，把一个 SKU 多天的 `stay_seconds` 累加成月度停留时长是允许的，`pv` 同样可相加。但 `uv` 不可跨行相加，若后续想看访客规模，不能把各天的 `uv` 求和，应另按去重口径处理。

本次已交付，并沉淀为固定报表。
