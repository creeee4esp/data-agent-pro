# 变更公告：指标计算规则说明（pay_amt）

## 变更说明

`pay_amt` 的口径这里说明一下，免得跟 GMV 混着用：支付金额按支付日期归属，与按下单日期归属的 GMV 不同。

### 口径要点

也就是说，一笔订单的支付金额算在它实际支付的那天，而 GMV 是按下单日期归属的。两者归属维度不一样，所以同一批订单在按日/按月统计时，`pay_amt` 和 GMV 很可能对不上，这是正常的，别当成数据有问题。

### 生效与影响

口径说明自 `2025-05-07` 起对齐。这是对既有算法的澄清，不改数、不回刷。用到支付金额的报表无需改动，按这个归属口径理解即可。
