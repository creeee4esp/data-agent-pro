# 取数需求单 REQ-2025-0120

## 需求

客服部想要 2025-05 单月、按退款原因看每天的退款金额 `refund_amount`（元），不加筛选，用来看看这个月退款主要集中在哪些原因上，方便针对性改进服务。

## 结论

`dws_trade_reason_refund_1d` 是退款原因粒度的按日退款汇总表，拿它来做正合适。字段取 `stat_date`、`refund_reason`、`refund_cnt`、`refund_amount`，按 `stat_date` 限定在 2025-05。

口径上可以放心：退款金额 `refund_amount` 和退款笔数 `refund_cnt` 都是可以跨行相加的，把某个退款原因整月累加、或者把各原因汇成当月总额再看占比，都没问题，不会重复计算。客服部可以据此排出当月退款原因的金额和笔数排名。

这次已经按一次性取数交付客服部了。
