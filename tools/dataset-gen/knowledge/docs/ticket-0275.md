# 取数需求单 REQ-2025-0275

## 需求

市场部在 2025-11-23 提出取数，关注 2025-07 的已支付订单明细金额（`paid_amount`），希望按用户粒度、日度交易口径查看，不设筛选条件。本单编号 REQ-2025-0275，处理人商品数据组。市场部想从单用户、按天的支付明细切入，观察当月的消费贡献分布。

## 结论

`dws_trade_user_order_1d` 即 DWS-用户粒度交易汇总（日）对应本次取数，取 `stat_date`、`buyer_id`、`order_cnt`、`paid_order_cnt`、`paid_amount`，报告期 `stat_date` 取 2025-07。

分析时要留意加和口径：`paid_amount` 可跨行相加，把各用户、各天的 `paid_amount` 汇总得到当月总金额是准确的。但 `order_cnt` 与 `paid_order_cnt` 都不可跨行相加，涉及下单数或支付订单数时不要直接求和，否则会重复计数。

本次已交付一次性取数结果。
