# 取数需求单 REQ-2025-0013

## 需求

财务部于 2025-01-14 正式提出取数需求 REQ-2025-0013。需求方请求提供收货省份粒度的已签收单数 `signed_cnt`，统计口径为按日汇总，时间范围为 2025-01，不设筛选条件。该数据用于按省份核对签收履约情况。

## 结论

`dws_lgs_prov_ship_1d` 经确认为本次取数来源表，由物流数据组负责处理与交付。取数维度采用 `stat_date` 与 `receiver_province`，输出指标为 `signed_cnt` 已签收单数。关于可加性，特此说明：`ship_cnt` 与 `signed_cnt` 可跨行相加，按省份或按日汇总时可直接求和；`avg_ship_hours` 为平均发货时长，不可跨行相加，如需整体平均值须回源按单量加权计算，不得对该列直接求和。本需求已交付一次性取数结果。
