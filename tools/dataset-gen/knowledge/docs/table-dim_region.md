# 表说明：dim_region（DIM-省份与大区维表）

## 概述

`dim_region` 为省份到大区的映射维表，归属 DIM 层，表注释为 DIM-省份与大区维表，当前共 16 行。其作用是为带省份的事实数据补充所属大区，便于按大区聚合。使用时应注意，该表仅覆盖已出现过的省份，未在上游出现的省份不会有对应大区。

## 字段

- `province` 为 varchar(20) 类型的省份，是本表的主键粒度，每个省份一行。
- `region` 为 varchar(10) 类型的大区，取值如华东、华南、华北、华中、西南、西北，未匹配到的省份归为其他。

## 上下游

`dim_region` 的上游为 `ods_user_info_di` 与 `ods_trade_order_di`，加工时对两表中出现的省份取并集，再按既定规则映射为大区。该表当前无下游表，供分析按需关联使用。

## 使用注意

`dim_region` 适用于将省份维度上卷到大区，例如把按省份的销售关联本表后按 `region` 汇总。该表为静态映射，不含任何度量，不能用于统计销量、金额等指标。另需注意其省份来源于用户常住地与收货地的并集，与单一事实表的省份集合未必完全一致。本家族存在备份表 `dim_region_bak` 及带日期备份 `dim_region_bak_20250123` 等，均为特定时点的留存副本，不随任务更新、未必完整，不得用于关联或统计，口径一律以 `dim_region` 为准。
