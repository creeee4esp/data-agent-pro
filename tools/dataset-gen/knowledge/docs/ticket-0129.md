# 取数需求单 REQ-2025-0129

## 需求

财务部希望了解 2025-01 至 2025-02 期间，各会员等级按周的购买件数 `item_qty`，不设筛选，目的是从销量视角观察不同等级会员的贡献结构，辅助权益成本与收益的测算。

## 结论

`dws_trade_level_order_1w` 是会员等级粒度的按周下单汇总表，字段含 `stat_date`、`member_level`、`order_cnt`、`item_qty`、`paid_amount`，可直接满足需求。取数按 `stat_date` 限定在 2025-01 至 2025-02 的周区间。

从口径上分析，购买件数 `item_qty` 是可跨行相加的，把某等级两个月各周累加、或把各等级汇成大盘，都成立，适合做等级间销量占比。同表的已支付明细金额 `paid_amount` 同样可加；但下单数 `order_cnt` 不可相加，若财务一并关注单量，别跨周累加，以免订单重复计数，应逐行看或改用可加指标。

本次已交付，并附上 SQL，供财务部自助复用。
