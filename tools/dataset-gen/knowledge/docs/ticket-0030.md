# 取数需求单 REQ-2025-0030

## 需求

客服部于 2025-02-02 提出取数需求 REQ-2025-0030，想要会员等级粒度的购买件数 `item_qty`，口径按日，时间范围 2025-01，没有筛选条件。分析意图是看不同会员等级在当月的购买件数差异，支撑客服侧对会员行为的理解。

## 结论

`dws_trade_level_order_1d` 作为来源表支撑这次取数，由数据平台组承接。维度从 `stat_date`、`member_level` 展开，输出指标为 `item_qty` 购买件数。使用上有一点要交代：`item_qty` 与 `paid_amount` 可以跨行相加，按会员等级或按日汇总时直接 SUM 即可；而 `order_cnt` 是订单去重计数，不具备可加性，跨行相加会重复，整体口径需回源计算。本需求已交付，附 SQL 供需求方自助复用。
