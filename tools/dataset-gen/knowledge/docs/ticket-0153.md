# 取数需求单 REQ-2025-0153

## 需求

市场部于 2025-06-29 提出的需求，核心是想算一算利润和毛利。从沟通中可以看出，市场部希望在现有交易数据的基础上进一步衡量盈利能力，判断不同活动或品类到底赚不赚钱，而不只是停留在成交金额这一层。

## 结论

利润与毛利这两个指标目前无法满足，原因在于口径上缺了关键一环——数据仓库里只有成交和支付侧的金额，并没有商品成本数据，没有成本就无法算出利润，更谈不上毛利率。与其硬凑一个不可信的数字，不如换个能落地的视角：可以用已支付订单的明细金额这类可加和的成交口径，配合退款金额来观察净收入的变化，也可以按品类、品牌拆解成交结构，找出贡献最高的部分。待后续接入成本数据后，再来补齐利润口径的核算。本次结论为无法满足，已向市场部说明原因并给出可替代的分析方向。
