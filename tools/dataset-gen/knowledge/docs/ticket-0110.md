# 取数需求单 REQ-2025-0110

## 需求

市场部现提出取数需求，拟获取 2025-02 至 2025-03 期间各品牌按月的评价数 `review_cnt`，不附加筛选条件，用于品牌口碑声量的跟踪与沉淀。

## 结论

经评估，`dws_item_brand_review_1m` 系品牌粒度的按月评价汇总表，可满足本次要求。所取字段为 `stat_date`、`brand_name`、`review_cnt`、`good_cnt`、`avg_rating`，时间范围依 `stat_date` 限定于 2025-02 至 2025-03。

经核验口径，评价数 `review_cnt` 与好评数 `good_cnt` 均可跨行相加，故按品牌跨月、或按月跨品牌汇总以得到总体声量，均属可行。惟平均评分 `avg_rating` 为平均值，不可相加，如需品牌整体或跨月的评分口径，应以 `review_cnt` 作权重重新加权，不得直接取简单平均。

本需求已交付，并沉淀为固定报表。
