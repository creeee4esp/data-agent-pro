# 取数需求单 REQ-2025-0028

## 需求

管理层于 2025-01-30 提出取数需求 REQ-2025-0028，关注的是承运商粒度的平均发货时长 `avg_ship_hours`（单位小时），希望按月汇总，时间范围 2025-01，不设筛选条件。背后的意图是横向比较各承运商的时效表现，为合作评估提供依据。

## 结论

`dws_lgs_carrier_ship_1m` 作为来源表支撑这次分析，由用户数据组承接。维度从 `stat_date`、`carrier` 展开，输出指标为 `avg_ship_hours` 平均发货时长。这里有个使用上的要点需要讲清楚：`avg_ship_hours` 是平均值，不能跨行相加，如果要得到跨承运商或跨期的整体平均发货时长，必须回到单量层面做加权，直接把各行该列相加会得到没有意义的数字；而同表的 `ship_cnt`、`signed_cnt` 则是可以跨行相加的。本需求已交付，并沉淀为固定报表。
