# 取数需求单 REQ-2025-0045

## 需求

会员中心于 2025-02-19 提出取数需求 REQ-2025-0045，要承运商粒度的发货单数 `ship_cnt`，口径按月，时间范围 2025-02，无筛选条件。诉求是看各承运商当月的发货规模。

## 结论

`dws_lgs_carrier_ship_1m` 为本次用表，由交易数据组处理交付。维度取 `stat_date`、`carrier`，指标输出 `ship_cnt` 发货单数。可加性提示：`ship_cnt`、`signed_cnt` 可跨行相加，按承运商或按月汇总可直接 SUM；`avg_ship_hours` 为平均发货时长，不能跨行相加，整体平均需按单量加权。本需求已交付，附 SQL 供需求方自助复用。
