# 变更公告：调度时间调整（dwd_trade_order_detail_di）

## 变更说明

`dwd_trade_order_detail_di` 调整了调度开始时间，由交易数据组发布，2025-11-24 生效。

从调度安排看，该表作业开始时间由原 05:00 后移至 05:30。之所以顺延 30 分钟，是为错开资源高峰，调整后产出时间相应后移，但仍能在当日完成。

值得关注的是，`dwd_trade_order_detail_di` 作为订单明细层被众多下游引用，时间后移意味着依赖它的汇总与报表作业可能相应延后可用。建议使用方复核自身作业的触发时间与依赖设置，确保在本表产出完成后再启动下游任务；若存在早于 05:30 读取本表的定时作业，请及时调整，以免取到未更新的数据。
