# 取数需求单 REQ-2025-0269

## 需求

管理层在 2025-11-15 提出取数，关注 2025-07 至 2025-09 的平均评分（`avg_rating`），希望按品牌粒度、月度口径观察三个月内各品牌的口碑走势，不设筛选条件。本单编号 REQ-2025-0269，处理人用户数据组。管理层想从评分变化判断各品牌的口碑趋势。

## 结论

`dws_item_brand_review_1m` 即 DWS-品牌粒度评价汇总（月）支撑本次取数，取 `stat_date`、`brand_name`、`review_cnt`、`good_cnt`、`avg_rating`，报告期 `stat_date` 覆盖 2025-07 至 2025-09。

分析时有个关键口径要强调：`avg_rating` 是平均值，不可跨行相加，既不能把各品牌的 `avg_rating` 相加，也不能把一个品牌三个月的 `avg_rating` 简单取算术平均来代表整体，若要跨品牌或跨月的总体平均评分，应以 `review_cnt` 为权重加权。`review_cnt`、`good_cnt` 可跨行相加。

考虑到口碑需持续跟踪，本次已交付，并沉淀为固定报表。
