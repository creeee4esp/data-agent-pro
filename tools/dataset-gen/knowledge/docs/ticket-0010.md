# 取数需求单 REQ-2025-0010

## 需求

财务部在 2025-01-13 提了需求 REQ-2025-0010，想要商品 SKU 粒度的浏览量 `pv`，按周汇总，时间范围 2025-01，没有筛选条件。他们是想看各 SKU 当月的浏览热度，配合财务侧的盘点。

## 结论

`dws_traffic_sku_visit_1w` 这张表能直接用，由交易数据组接的单。按周取 2025-01 数据，维度用 `stat_date`、`sku_id`，指标给 `pv` 浏览量。提醒一下可加性：`pv` 和 `stay_seconds` 能跨行相加，按 SKU 汇总直接 SUM 就行；`uv` 不能跨行相加，是去重访客数，不同行加起来会重复，要整体 `uv` 得回源去重。这次已交付一次性取数结果。
