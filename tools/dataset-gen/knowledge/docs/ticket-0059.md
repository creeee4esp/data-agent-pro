# 取数需求单 REQ-2025-0059

## 需求

会员中心于 2025-03-06 提出取数需求 REQ-2025-0059，关注访问用户粒度的总停留秒数 `stay_seconds`，希望按月汇总，时间范围 2025-02，不设筛选条件。分析意图是看当月各访客的停留时长分布，判断用户黏性。

## 结论

`dws_traffic_visitor_visit_1m` 作为来源表支撑这次取数，由商品数据组承接。维度从 `stat_date`、`visitor_id` 展开，输出指标为 `stay_seconds` 总停留秒数。使用上需交代清楚：`pv` 与 `stay_seconds` 可以跨行相加，按访客或按月汇总时可直接 SUM；而 `uv` 为去重访客数，不具备可加性，跨行相加会重复计数，若要整体 `uv` 须回源去重。本需求已交付，并沉淀为固定报表。
