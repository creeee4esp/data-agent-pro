# 变更公告：新表上线（dws_item_brand_review_1w）

## 变更说明

`dws_item_brand_review_1w`（DWS-品牌粒度评价汇总（周））上线，补足了品牌维度周度评价汇总的缺口。

### 背景与内容

此前做品牌的周度评价趋势，往往要从评价明细临时聚合，既慢又容易口径不一。新表直接从 `dwd_item_review_di` 加工而来，把品牌维度的周度评价数据沉淀下来，分析时可直接取用。

### 生效、影响与动作

表自 `2025-07-17` 起正式产出。作为新增产出，它不改动任何现有表的结构与数据。原先自行聚合品牌周度评价的同学，建议改接 `dws_item_brand_review_1w`，减少重复加工。

商品数据组发布。
