# 变更公告：新表上线（dwd_item_review_di）

## 变更说明

`dwd_item_review_di` 上线了，给大家说一下，2025-10-18 生效，流量数据组发布。

表注释是“DWD-评价明细”，上游用到两张表：`ods_item_review_di` 和 `dim_sku`。简单说就是在原始评价数据的基础上，关联了商品维表 `dim_sku`，补齐了商品相关维度，产出一张干净的评价明细，方便下游直接用。

要用的同学从生效日起接 `dwd_item_review_di` 就行，粒度是评价明细。提醒一下，它依赖 `ods_item_review_di` 和 `dim_sku` 两个上游，任意一个出问题或跑得晚，这张表都可能延迟产出，依赖它的作业记得关注上游状态。
