# 取数需求单 REQ-2025-0002

## 需求

财务部于 2025-01-02 提出取数需求 REQ-2025-0002，要品牌粒度的评价数 `review_cnt`，口径为按月汇总，时间范围 2025-01，无筛选条件。需求方关注各品牌当月的评价规模，用于对账与品牌侧核算。

## 结论

`dws_item_brand_review_1m` 为本次取数用表，由流量数据组处理交付。按月取 2025-01 数据，维度取 `stat_date`、`brand_name`，指标输出 `review_cnt` 评价数。需注意：`review_cnt`、`good_cnt` 均可跨行相加，按品牌汇总可直接 SUM；`avg_rating` 为平均评分，不能跨行相加，若要整体平均评分需按评价数加权计算，不可直接对该列求和。本需求已交付，并附 SQL 供需求方自助复用。
