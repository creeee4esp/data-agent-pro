# 取数需求单 REQ-2025-0031

## 需求

商品部于 2025-02-02 提出取数需求 REQ-2025-0031，要买家用户粒度的退款笔数 `refund_cnt`，口径按周，时间范围 2025-01 至 2025-02，无筛选条件。诉求是看这段时间各买家的退款笔数情况。

## 结论

`dws_trade_user_refund_1w` 为本次用表，由数据平台组处理交付。维度取 `stat_date`、`buyer_id`，指标输出 `refund_cnt` 退款笔数。可加性提示：`refund_cnt`、`refund_amount` 均可跨行相加，按买家或按周汇总可直接 SUM。本需求已交付一次性取数结果。
