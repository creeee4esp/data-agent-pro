# 指标说明：客单价（客单价）

## 计算公式

客单价为派生指标，计算方式是支付金额 / 支付订单数（或 GMV / 支付订单数），按需求说明分母。换言之，分子可取支付金额或 GMV，分母为支付订单数，具体选用哪一个分子应在需求中明确说明，以免口径歧义。由于它是两个量相除的比率，不具备可加性：各期客单价不能直接相加或取算术平均，若需更长周期的客单价，应将分子与分母各自按该周期汇总后再相除。

## 取哪张表

客单价本身不落在明细或汇总表的字段中，需由分子分母现算。参考表为 `ads_trade_gmv_monthly`，可从中取得 GMV 与支付订单数后相除得到月度客单价。进行计算时须保证分子与分母取自同一时间范围与同一口径。

## 来源与历史变化

客单价由支付金额（或 GMV）与支付订单数派生而来，不独立存储，分母口径以具体需求说明为准。该指标自上线以来未调整计算规则，口径一致，可直接用于跨期趋势比较。
