# 取数需求单 REQ-2025-0021

## 需求

物流部在 2025-01-22 提了需求 REQ-2025-0021，想要访问渠道粒度的总停留秒数 `stay_seconds`，按月汇总，时间范围 2025-01，没有筛选条件。他们想看各访问渠道当月用户的停留时长表现。

## 结论

`dws_traffic_vchannel_visit_1m` 这张表就能满足，由数据平台组接的单。按月取 2025-01 数据，维度用 `stat_date`、`channel`，指标给 `stay_seconds` 总停留秒数。可加性要提醒：`pv` 和 `stay_seconds` 能跨行相加，按渠道汇总直接 SUM 就行；`uv` 不能跨行相加，是去重访客数，不同行加起来会重复，整体 `uv` 要回源去重。这次已交付，附 SQL 供需求方自助复用。
