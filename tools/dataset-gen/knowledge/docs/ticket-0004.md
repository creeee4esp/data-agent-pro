# 取数需求单 REQ-2025-0004

## 需求

REQ-2025-0004，客服部于 2025-01-03 提出。

- 需求方：客服部
- 诉求：用户粒度的下单数 `order_cnt`
- 口径：按日汇总
- 时间范围：2025-01
- 筛选：无

## 结论

`dws_trade_user_order_1d` 作为交付用表，由流量数据组处理。

- 维度：`stat_date`、`buyer_id`
- 输出指标：`order_cnt` 下单数
- 可加性提示：`paid_amount` 可跨行相加；`order_cnt`、`paid_order_cnt` 不可跨行相加，它们是去重后的用户级计数，不同行直接相加会重复，如需整体去重口径须回源计算
- 交付方式：已交付一次性取数结果
