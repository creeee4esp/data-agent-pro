# 变更公告：新表上线（dws_trade_sku_order_1w）

## 变更说明

`dws_trade_sku_order_1w`（DWS-商品SKU 粒度下单汇总（周））已上线，填补了 SKU 粒度周度下单汇总的空缺。

### 背景与内容

此前做 SKU 级别的周度下单趋势，往往要从明细临时聚合，既慢又容易口径不一。新表直接从 `dwd_trade_order_detail_di` 加工而来，把 SKU 粒度的周度下单量沉淀下来，分析时可直接取用。

### 生效、影响与动作

表自 `2025-01-26` 起正式产出。作为新增产出，它不改动任何现有表的结构和数据。原先自行聚合 SKU 周度下单的同学，建议改接 `dws_trade_sku_order_1w`，以减少重复加工。

物流数据组发布。
