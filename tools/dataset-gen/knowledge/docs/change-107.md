# 变更公告：表注释修正（mkt_coupon_receive）

## 变更说明

`mkt_coupon_receive` 的表注释这次做个修正，跟大家同步一下，2025-09-07 生效，数据平台组发布。

之前这张表的注释不太准确，容易让人搞错它存的是什么，现在把正确注释定为“用户领券记录表”。说明一下：这只是改注释，表结构、字段和历史数据都没动，取数结果不会有任何变化，大家不用担心跑数受影响。

需要大家做的事情很简单：以后挑数据源时，按“用户领券记录表”来理解 `mkt_coupon_receive` 的用途就行；现有 SQL 不用改，生效后方便的话刷一下元数据缓存，让新注释正确显示出来。
