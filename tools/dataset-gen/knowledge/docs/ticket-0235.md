# 取数需求单 REQ-2025-0235

## 需求

商品部于 2025-10-05 正式提出取数申请，请求提供 2025-01 至 2025-03 的浏览量（`pv`），统计口径为商品 SKU 粒度访问周度汇总，不设筛选条件。本单编号 REQ-2025-0235，交由商品数据组承办。

## 结论

`dws_traffic_sku_visit_1w` 即 DWS-商品SKU 粒度访问汇总（周）为本次取数之依据表，取用 `stat_date`、`sku_id`、`pv`、`uv`、`stay_seconds`，报告期 `stat_date` 覆盖 2025-01 至 2025-03 的各周。

须予说明：`pv` 可跨行相加，将各 SKU、各周的 `pv` 累加以得浏览量合计系属合理，`stay_seconds` 亦可跨行相加。惟 `uv` 为去重访客数，不可跨行相加，如涉及访客口径汇总，务请另按去重方式处理。
