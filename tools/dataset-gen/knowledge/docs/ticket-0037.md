# 取数需求单 REQ-2025-0037

## 需求

商品部在 2025-02-09 提了需求 REQ-2025-0037，想要收货省份粒度的支付金额 `pay_amt`（单位元），按日汇总，时间范围 2025-02，并且只看湖南省。他们想单独盯一下湖南省当月的支付金额走势。

## 结论

`dws_trade_prov_pay_1d` 这张表能满足，由交易数据组接的单。按日取 2025-02 数据，维度用 `stat_date`、`receiver_province`，并在 `receiver_province` 上筛出湖南省，指标给 `pay_amt` 支付金额。可加性上比较省心，`pay_cnt` 和 `pay_amt` 都能跨行相加，按日汇总直接 SUM 就行。这次已交付一次性取数结果。
