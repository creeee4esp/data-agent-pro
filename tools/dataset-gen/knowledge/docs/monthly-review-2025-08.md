# 商品评价月报：2025-08

## 概览

商品评价月报 2025-08 期收录评价共 1,489 条，覆盖七个一级品类。

- 平均评分最高的品类是美妆个护，2025-08 为 4.30 分，好评率 83.06%。
- 平均评分最低的品类是电脑办公，2025-08 为 3.94 分，好评率 71.69%。
- 评价量最大的品类是服装鞋帽，共 429 条；最少的是食品饮料，共 45 条。
- 好评率最高的是手机数码 84.50%，最低的是电脑办公 71.69%。
