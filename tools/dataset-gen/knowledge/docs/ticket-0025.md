# 取数需求单 REQ-2025-0025

## 需求

会员中心在 2025-01-27 提了需求 REQ-2025-0025，想要品牌粒度的好评数 `good_cnt`（4 星及以上），按周汇总，时间范围 2025-01，没有筛选条件。他们想看各品牌当月的好评积累。

## 结论

`dws_item_brand_review_1w` 这张表能满足，由数据平台组接的单。按周取 2025-01 数据，维度用 `stat_date`、`brand_name`，指标给 `good_cnt` 好评数。可加性提醒下：`review_cnt` 和 `good_cnt` 能跨行相加，按品牌或按周汇总直接 SUM 就行；`avg_rating` 是平均评分，不能跨行相加，要整体平均得按评价数加权。这次已交付，附 SQL 供需求方自助复用。
