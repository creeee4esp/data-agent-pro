# 取数需求单 REQ-2025-0023

## 需求

会员中心于 2025-01-24 提出取数需求 REQ-2025-0023，关注的是商品 SKU 粒度的评价数 `review_cnt`，希望以周为口径汇总，时间范围锁定 2025-01，不附加任何筛选条件。背后的分析意图是观察单个 SKU 在一个月内评价量的积累节奏，为后续的商品口碑评估提供输入。

## 结论

`dws_item_sku_review_1w` 是支撑这次取数的来源表，由用户数据组承接处理。分析从 `stat_date`、`sku_id` 两个维度展开，输出指标为 `review_cnt` 评价数。在使用层面有一点必须交代清楚：`review_cnt` 与 `good_cnt` 是可以跨行相加的，按 SKU 或按周做汇总时可直接 SUM；而 `avg_rating` 作为平均评分不具备可加性，若要得到跨行的整体平均评分，需以评价数为权重加权计算，直接对该列求和会得到错误结论。本需求已交付一次性取数结果。
