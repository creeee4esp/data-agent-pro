# 取数需求单 REQ-2025-0134

## 需求

市场部希望了解 2025-01 至 2025-03 期间，各收货省份按日的退款金额 `refund_amount`（元），不设筛选，目的是从退款资金角度观察各省的售后表现，为区域营销和服务投入提供参考。

## 结论

`dws_trade_prov_refund_1d` 是收货省份粒度的按日退款汇总表，字段含 `stat_date`、`receiver_province`、`refund_cnt`、`refund_amount`，可直接满足需求。取数按 `stat_date` 限定在 2025-01 至 2025-03。

从口径上分析，退款金额 `refund_amount` 与退款笔数 `refund_cnt` 都是可跨行相加的指标，把某省跨日累加成期间退款合计、或把各省汇成大盘再看占比，都成立，适合做区域退款规模的排序与对比。市场部可据此锁定退款金额偏高的省份，再结合退款原因做深入分析。

本次已按一次性取数交付市场部。
