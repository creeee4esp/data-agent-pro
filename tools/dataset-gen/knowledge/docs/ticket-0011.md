# 取数需求单 REQ-2025-0011

## 需求

运营部于 2025-01-13 正式提出取数需求 REQ-2025-0011。需求方请求提供一级品类粒度的评价数 `review_cnt`，统计口径为按日汇总，时间范围为 2025-01，不设筛选条件。该数据用于观察各一级品类当月的评价积累情况。

## 结论

`dws_item_cate1_review_1d` 经确认为本次取数来源表，由交易数据组负责处理与交付。取数维度采用 `stat_date`、`category1_id` 与 `category1_name`，输出指标为 `review_cnt` 评价数。关于可加性，特此说明：`review_cnt` 与 `good_cnt` 可跨行相加，按一级品类或按日汇总时可直接求和；`avg_rating` 为平均评分，不可跨行相加，如需得到整体平均评分，应以评价数为权重加权计算，不得对该列直接求和。本需求已交付一次性取数结果。
