# 变更公告：调度时间调整（ads_pay_channel_monthly）

## 变更说明

`ads_pay_channel_monthly` 调度开始时间予以调整，现予通告，自 2025-08-14 起生效，由数据平台组发布。

经统筹资源与上游依赖，该表作业开始时间由原 05:00 调整为 05:30。调度顺延 30 分钟后，产出时间相应后移，但当日仍可按时完成。

影响范围为依赖 `ads_pay_channel_monthly` 产出的下游作业、报表及取数任务。请相关使用方核对自身作业的触发时间与依赖设置，确保在该表产出完成后再启动下游任务；如存在早于 05:30 读取本表的定时作业，请及时调整，避免读取到未更新数据。
