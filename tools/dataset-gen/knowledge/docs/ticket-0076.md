# 取数需求单 REQ-2025-0076

## 需求

商品部想拉一份 2025-01 至 2025-03、按买家用户粒度的周度下单数 `order_cnt`，没有额外筛选，用来摸底这季度各买家的下单频次分布。

## 结论

`dws_trade_user_order_1w` 就是买家用户粒度的按周下单汇总表，拿它来做正好。字段取 `stat_date`、`buyer_id`、`order_cnt`、`item_qty`、`paid_amount`，按 `stat_date` 卡在 2025-01 到 2025-03 的周区间就行。

有个坑得提前说清楚：`order_cnt` 不能跨行相加。想看单个买家这一季度总共下了多少单，不能把他各周的 `order_cnt` 直接加起来，那样会重复算；要按最细行逐条看，或者换可加的 `item_qty`、`paid_amount` 来衡量规模。

这次已经交付，并附上了 SQL，商品部后面想换时间段可以自己复用。
