# 取数需求单 REQ-2025-0292

## 需求

管理层于 2025-12-21 提出，想看 `order_cnt`（下单数）在各收货省份的分布，粒度是收货省份下单月汇总，时间范围 2025-04，没有额外筛选。

## 结论

`dws_trade_prov_order_1m` 这张表能满足需求，商品数据组用它出数。表里的字段有 `stat_date`、`receiver_province`、`order_cnt`、`item_qty`、`paid_amount`。

有个口径要提醒一下：`order_cnt` 不能跨行相加，把各省份的下单数加起来会重复计算同一订单，想要全国总下单数得回订单明细去重；`item_qty` 和 `paid_amount` 可以跨行相加，直接汇总没问题。

这次已经交付，并沉淀为固定报表，后续管理层可以直接查。
