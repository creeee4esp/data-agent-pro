# 数据事故报告：2025-02-09 dws_item_sku_review_1m 产出延迟

## 现象

`dws_item_sku_review_1m`（DWS-商品SKU 粒度评价汇总（月））于 2025-02-09 被发现产出延迟。从时间线梳理，该表在例行产出窗口内迟迟没有刷新，商品 SKU 粒度的月度评价汇总长时间停留在上一分区状态，下游取数时读不到当天预期的结果。整段延迟持续了 3 小时。

## 原因与影响范围

`dws_item_sku_review_1m` 的延迟，经分析根源在于上游 ODS 同步超时。上游 ODS 数据同步未在约定时间内完成，使得本表的计算入口被卡住，调度被动顺延，最终形成 3 小时的延迟。就波及面来看，本次事故没有影响到任何下游表，问题被局限在该表自身。

处理方面，物流数据组通过清理重复分区后重跑的方式恢复产出。目前数据已完成补数，表重新回到正常节奏。
