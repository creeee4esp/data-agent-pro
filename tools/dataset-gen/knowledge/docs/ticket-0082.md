# 取数需求单 REQ-2025-0082

## 需求

会员中心现提出取数需求，拟获取 2025-01 至 2025-03 期间各买家用户按日的支付订单数 `paid_order_cnt`，不附加筛选条件，用于评估会员的支付转化规模。

## 结论

经评估，`dws_trade_user_order_1d` 系用户粒度的按日交易汇总表，可满足本次要求。所取字段为 `stat_date`、`buyer_id`、`order_cnt`、`paid_order_cnt`、`paid_amount`，时间范围依 `stat_date` 限定于 2025-01 至 2025-03。

需郑重提示：下单数 `order_cnt` 与支付订单数 `paid_order_cnt` 均不可跨行相加，若将同一买家多日或多买家的数值累加，将造成订单重复计数。如需衡量累计规模，应采用可加和的已支付明细金额 `paid_amount`，或按最细行逐条核验。

本需求已按一次性取数交付会员中心。
