# 取数需求单 REQ-2025-0043

## 需求

运营部在 2025-02-19 提了需求 REQ-2025-0043，想要一级品类粒度的好评数 `good_cnt`（4 星及以上），按周汇总，时间范围 2025-02，没有筛选条件。他们想看各一级品类当月的好评表现。

## 结论

`dws_item_cate1_review_1w` 这张表能满足，由交易数据组接的单。按周取 2025-02 数据，维度用 `stat_date`、`category1_id`、`category1_name`，指标给 `good_cnt` 好评数。可加性提醒下：`review_cnt` 和 `good_cnt` 能跨行相加，按品类或按周汇总直接 SUM 就行；`avg_rating` 是平均评分，不能跨行相加，要整体平均得按评价数加权算。这次已交付，附 SQL 供需求方自助复用。
