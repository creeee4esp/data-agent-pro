# 取数需求单 REQ-2025-0152

## 需求

会员中心于 2025-06-27 提出的需求，围绕品牌维度的评价数 `review_cnt` 展开，按周汇总，报告期为 2025-06，不设筛选条件。从沟通来看，会员中心关注的是当月各品牌在会员群体中的评价活跃度变化，希望能稳定地按周追踪，而非一次性看完就结束。

## 结论

`dws_item_brand_review_1w` 正好承载这一诉求，取数落在 `stat_date`、`brand_name`、`review_cnt`、`good_cnt`、`avg_rating` 这几个字段上，以 `stat_date` 限定 2025-06 后按品牌与周铺开即可。分析时需留意指标口径的差异：`review_cnt` 与 `good_cnt` 是可加和指标，跨周或跨品牌求和都没有问题；而 `avg_rating` 是平均评分，不能跨行直接相加，若要得到一段时间的整体平均，应按评价数加权重算。考虑到会员中心的长期跟踪需求，本次已交付，并沉淀为固定报表。
