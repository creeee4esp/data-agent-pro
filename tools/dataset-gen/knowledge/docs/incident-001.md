# 数据事故报告：2025-01-04 dws_trade_user_pay_1m 计算结果偏差

## 现象

`dws_trade_user_pay_1m`（DWS-买家用户粒度支付汇总（月））于 2025-01-04 被监控发现产出结果异常。经核查，该表当日计算结果出现偏差，买家用户粒度的月度支付汇总数值与预期不符，属计算结果偏差类事故。事故自发现起持续 6 小时。

## 原因与影响范围

`dws_trade_user_pay_1m` 本次偏差的根本原因系维表 SCD 处理错误，导致汇总计算在关联维度时取数不准，进而使支付汇总结果产生偏差。经排查，本次事故未波及任何下游表，影响范围限于该表自身。

处理方面，交易数据组在定位原因后对当天任务执行重跑并进行补数。截至报告出具，相关数据已完成补数，表内结果恢复正常，事故予以闭环。
