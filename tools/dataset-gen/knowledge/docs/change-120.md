# 变更公告：提醒：备份 / 副本表列名与正表不一致（lgs_shipment_20250219）

## 变更说明

`lgs_shipment_20250219` 为正表的备份副本，经核查其列名与正表不一致，由流量数据组发布，2025-10-10 生效。

具体差异为：正表中的列名为 `sign_time`，副本表 `lgs_shipment_20250219` 中对应列名为 `sign_tm`。两列记录内容一致，仅命名不同，直接套用正表 SQL 会因列不存在而报错。

影响范围为所有直接访问该备份副本的查询与脚本。请使用方引用 `lgs_shipment_20250219` 时，将 `sign_time` 改写为 `sign_tm`，并自查既有作业是否因列名差异而失败；如无必要，建议优先使用正表取数。
