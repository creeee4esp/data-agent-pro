# 变更公告：新表上线（ads_pay_channel_monthly）

## 变更说明

`ads_pay_channel_monthly`（ADS-支付渠道月度报表）上线了，做支付渠道月度分析的同学可以用起来。

### 这表是啥

它从 `dwd_trade_pay_di` 加工而来，按支付渠道汇总出月度报表。以前看各渠道的月度表现得自己拼，现在直接查这张就行，口径也统一。

### 生效与影响

从 `2025-06-25` 起正式产出。属于新增报表，不动任何现有表。有支付渠道月度分析需求的同学，直接接入 `ads_pay_channel_monthly` 即可。

交易数据组发布。
