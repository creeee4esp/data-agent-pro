# 取数需求单 REQ-2025-0072

## 需求

会员中心提的需求，想要 2025-02 至 2025-03 这两个月、按收货省份看每天的支付笔数 `pay_cnt`，不加任何筛选条件，用来对比各省会员的支付活跃情况。

## 结论

`dws_trade_prov_pay_1d` 正好是收货省份粒度的按日支付汇总表，直接拿来用就行。取 `stat_date`、`receiver_province`、`pay_cnt`，顺带把 `pay_amt` 也带上，方便他们算客单。

这里要提醒一句：`pay_cnt` 和 `pay_amt` 都是可以跨行相加的，所以把一个省多天的数字加起来、或者把一个日期跨省加起来做月度和全国汇总都没问题，不用担心重复计算。时间范围按 `stat_date` 落在 2025-02 到 2025-03 之间过滤即可。

结果已经按一次性取数交付给会员中心了。
