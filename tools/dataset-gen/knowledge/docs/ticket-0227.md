# 取数需求单 REQ-2025-0227

## 需求

会员中心在 2025-09-29 提出取数，关注 2025-08 的退款金额（`refund_amount`），希望按退款原因粒度、周度口径看看哪些原因带来的退款金额最高，不设筛选条件。本单编号 REQ-2025-0227，处理人交易数据组。会员中心想据此定位当月退款的主要成因。

## 结论

`dws_trade_reason_refund_1w` 即 DWS-退款原因粒度退款汇总（周）贴合该诉求，取 `stat_date`、`refund_reason`、`refund_cnt`、`refund_amount`，报告期 `stat_date` 取 2025-08 内各周。

加和方面这张表较为直观：`refund_cnt` 与 `refund_amount` 都可跨行相加，把各退款原因、各周的 `refund_amount` 汇总得到月度总退款金额，再按原因排序即可看出主次，口径准确可靠。

考虑到退款监控有持续需求，本次已交付，并沉淀为固定报表。
