# 取数需求单 REQ-2025-0281

## 需求

财务部在 2025-11-30 提出取数，关注 2025-07 的评价数（`review_cnt`），希望按品牌粒度、月度口径了解各品牌当月的评价规模，不设筛选条件。本单编号 REQ-2025-0281，处理人商品数据组。财务部想从评价量侧面判断各品牌当月的活跃程度。

## 结论

`dws_item_brand_review_1m` 即 DWS-品牌粒度评价汇总（月）对应本次取数，取 `stat_date`、`brand_name`、`review_cnt`、`good_cnt`、`avg_rating`，报告期 `stat_date` 取 2025-07。

加和方面：`review_cnt` 与 `good_cnt` 可跨行相加，把各品牌的 `review_cnt` 汇总得到全站评价数，或按品牌排序找出评价集中的品牌，口径准确。需要提醒 `avg_rating` 为平均值，不可跨行相加，如需整体平均评分应以 `review_cnt` 加权。

考虑到评价规模需持续监测，本次已交付，并沉淀为固定报表。
