# 取数需求单 REQ-2025-0197

## 需求

市场部于 2025-08-21 正式提出取数申请，需求对象为访问用户粒度的总停留秒数 `stay_seconds`，按日汇总，报告期区间为 2025-05 至 2025-07，不附加任何筛选条件。该数据拟用于分析各访问用户在三季度初的停留时长分布。

## 结论

`dws_traffic_visitor_visit_1d` 为本需求推荐用表，取数涉及 `stat_date`、`visitor_id`、`pv`、`uv`、`stay_seconds` 等字段，以 `stat_date` 限定 2025-05 至 2025-07 后按 `visitor_id` 输出即可。需提请注意：`stay_seconds` 与 `pv` 为可加和指标，跨日或跨用户求和均成立；而 `uv` 系去重访客数，不得跨行累加，若需一段时间的整体 `uv` 应回源重算。本需求已交付一次性取数结果。
