# 取数需求单 REQ-2025-0291

## 需求

运营部于 2025-12-21 提出的这项需求，关注 `order_cnt`（下单数）在不同会员等级上的分布，粒度为会员等级下单周汇总，时间范围锁定在 2025-03，没有附加筛选条件。业务方希望借此观察各等级会员在该月各周的下单活跃度。

## 结论

`dws_trade_level_order_1w` 为承接本需求的表，由流量数据组完成取数与分析。表中提供 `stat_date`、`member_level`、`order_cnt`、`item_qty`、`paid_amount` 五个字段，可按会员等级逐周拆解。

分析中需特别留意口径：`order_cnt` 不能跨行相加，跨等级或跨周累加会导致同一订单被重复计数，因此总下单数不能简单求和，应回到订单明细去重；`item_qty` 与 `paid_amount` 则可跨行相加，用于观察数量与金额的规模变化。

本次已交付，并沉淀为固定报表，供运营部持续跟踪各会员等级的下单表现。
