# 加工说明：ods_mkt_coupon_di

## 加工逻辑

`ods_mkt_coupon_di` 为 ODS-优惠券定义表，当前 30 行，是业务源表 `mkt_coupon` 在贴源层的落地。加工不做清洗与聚合，整表原样同步，仅在源表全部字段之外追加固定 ETL 时间列与分区列 `dt`，以记录抽取时间并支持按日分区管理。

```sql
INSERT INTO ods_mkt_coupon_di SELECT mkt_coupon.*, <固定 etl_time>, <分区 dt> FROM mkt_coupon
```

本表粒度与源表一致，一张券对应一行，是下游 `dim_coupon` 取券类型、门槛与面额等属性的依据。

## 依赖与调度

`ods_mkt_coupon_di` 依赖一张上游表，即业务源表 `mkt_coupon`。调度每日 01:00 开始，依赖上游全部成功后运行，处理前一天（T-1）的数据。作为 ODS 层任务，其运行时间早于下游各层。

## 质量检查

`ods_mkt_coupon_di` 发布前执行三项检查：主键 / 粒度唯一，确保优惠券不重复；关键字段非空；行数与前一天相比波动超过 30% 告警。

检查未通过将影响下游。优惠券重复会使 `dim_coupon` 按券关联时膨胀，核销统计被重复计算；关键字段为空会导致券类型等属性缺失；行数异常下降通常表明源表 `mkt_coupon` 未抽取完整，部分券在下游关联不上。出现告警应先核查源表后再行发布。
