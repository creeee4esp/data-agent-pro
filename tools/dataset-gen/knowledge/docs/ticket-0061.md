# 取数需求单 REQ-2025-0061

## 需求

财务部于 2025-03-08 提出取数需求 REQ-2025-0061，关注访问用户粒度的访客数 `uv`，希望按日汇总，时间范围覆盖 2025-02 至 2025-03，不设筛选条件。分析意图是跨这两个月追踪访客规模的日度走势，为财务侧的流量盘点提供输入。

## 结论

`dws_traffic_visitor_visit_1d` 作为来源表支撑这次取数，由物流数据组承接。维度从 `stat_date`、`visitor_id` 展开，输出指标为 `uv` 访客数。这里有个关键点必须讲清：`uv` 是去重访客数，不能跨行相加，把不同天或不同访客的 `uv` 相加会重复计数，若要整体 `uv` 必须回源去重；而同表的 `pv`、`stay_seconds` 可以跨行相加。本需求已交付，并沉淀为固定报表。
