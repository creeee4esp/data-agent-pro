# 数据事故报告：2025-12-03 dws_traffic_visitor_visit_1d 数据重复

## 现象

`dws_traffic_visitor_visit_1d`（DWS-访问用户粒度访问汇总（日））在 2025-12-03 被发现数据重复。从现象上看，访问用户粒度的日度访问汇总中出现了重复记录，同一访问用户的访问被叠加计入，汇总数值随之偏高。整段事故持续 12 小时。

## 原因与影响范围

`dws_traffic_visitor_visit_1d` 重复的根源，经分析可归结到任务重跑前未清理当天分区。重跑产生的数据与原有分区数据叠加，造成同一主体被重复统计，这是此类问题的典型链路。就波及面而言，本次事故未影响任何下游表，问题被限制在该表自身。

处理上，商品数据组通过修复 SQL 后回刷近 7 天的方式恢复数据。目前数据已完成补数，表恢复可用状态。
