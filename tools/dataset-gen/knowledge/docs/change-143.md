# 变更公告：指标计算规则说明（avg_ship_hours）

## 变更说明

`avg_ship_hours` 明确计算规则，由流量数据组发布，2025-12-16 生效。

从口径定义看，发货时长从支付时间算到发货时间，即以支付时间为起点、发货时间为终点计算这段时长。这样界定的意义在于，它衡量的是从用户付款到商品实际发出之间的仓配处理效率，而非包含配送在途的全链路时长。

对使用方的影响在于口径一致性：所有引用 `avg_ship_hours` 的报表与分析应据此复核。若此前的计算起点或终点与此不符，请同步调整为“支付时间到发货时间”，以免不同口径下的发货时长无法横向比较。此说明不改变底层加工逻辑，历史数据不回刷。
