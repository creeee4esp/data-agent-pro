# 会员等级消费月报：2025-03

## 概览

会员等级消费月报 2025-03 覆盖等级 1（普通）至等级 5（钻石）五档会员。

- 金额最高：等级 2，已支付明细金额 964,881.10 元。
- 金额次高：等级 3，824,204.40 元；等级 4，766,762.20 元。
