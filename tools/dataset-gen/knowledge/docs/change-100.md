# 变更公告：新表上线（dim_sku）

## 变更说明

`dim_sku` 正式上线，表注释为“DIM-商品维表（含品牌、两级品类）”，现予通告，自 2025-08-24 起生效，由交易数据组发布。

该表整合商品维度信息，涵盖品牌及两级品类。其上游为 `ods_item_sku_di`、`ods_item_brand_di` 与 `ods_item_category_di`，由上述来源加工汇聚而成。

影响范围为需要商品、品牌及品类维度关联的各类建模与分析场景。请使用方自生效日起按规范接入 `dim_sku` 作为统一商品维表，并核对原有自建维表或关联逻辑，逐步切换至本表以统一口径。上游任一来源异常，均可能影响本表产出，请关注依赖状态。
