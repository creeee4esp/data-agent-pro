# 取数需求单 REQ-2025-0113

## 需求

客服部希望了解 2025-01 至 2025-02 期间，各品牌按月的已支付明细金额 `paid_amount`（元），不设筛选，目的是从成交金额角度判断哪些品牌的售后咨询更密集、值得重点保障。

## 结论

`dws_trade_brand_order_1m` 是品牌粒度的按月下单汇总表，字段含 `stat_date`、`brand_name`、`order_cnt`、`item_qty`、`paid_amount`，可直接满足需求。取数按 `stat_date` 限定在 2025-01 至 2025-02。

从口径上分析，已支付明细金额 `paid_amount` 可跨行相加，把某品牌两个月累加成期间总额、或把多个品牌汇成大盘，都成立，适合做品牌金额排序。同表的 `item_qty` 同样可加；但下单数 `order_cnt` 不可相加，若客服一并关注单量规模，别跨月累加，以免订单重复计数，应逐行看或改用可加指标。

本次已交付，并沉淀为固定报表供客服部查看。
