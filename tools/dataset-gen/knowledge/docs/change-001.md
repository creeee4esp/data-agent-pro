# 变更公告：补充字段注释（dwd_trade_pay_di）

## 变更说明

`dwd_trade_pay_di` 的 `pay_id` 字段此前没有注释，这次给它补上了「支付单ID」的说明，方便大家在取数和写 SQL 时直接认出它的含义。

### 生效时间

变更已在 `2025-01-01`生效。补注释属于纯元数据改动，不影响任何已有数据和口径，历史分区无需回刷。

### 影响范围与使用方动作

影响面只在元数据层：之前按位置或凭经验引用 `pay_id` 的同学，现在能在表结构里直接看到字段含义。大家不需要改任何现有任务，若本地缓存了旧的表结构，刷新一下即可看到新注释。

本次变更由商品数据组发布。
