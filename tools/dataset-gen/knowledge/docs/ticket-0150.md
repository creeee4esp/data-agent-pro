# 取数需求单 REQ-2025-0150

## 需求

物流部于 2025-06-23 正式提出取数申请，需求对象为收货省份粒度的下单数 `order_cnt`，按月汇总，报告期区间为 2025-03 至 2025-04，不附加任何筛选条件。该数据拟用于分析二季度初各收货省份的订单规模分布。

## 结论

`dws_trade_prov_order_1m` 为本需求推荐用表，取数涉及 `stat_date`、`receiver_province`、`order_cnt`、`item_qty`、`paid_amount` 等字段，以 `stat_date` 限定 2025-03 至 2025-04 后按收货省份输出。需提请注意：`order_cnt` 系去重下单数，不得跨行累加，各省相加不等于全国总下单数；`item_qty` 与 `paid_amount` 则为可加和指标，汇总无碍。本需求已交付，并随附 SQL 供物流部自助复用。
