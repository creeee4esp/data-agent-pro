# 取数需求单 REQ-2025-0234

## 需求

市场部 2025-10-04 来问，能不能查询用户手机号等敏感信息，想用来做一些触达。单号 REQ-2025-0234，商品数据组接的。

## 结论

这条需求没法满足。手机号这类个人敏感信息属于隐私数据，不在我们数据仓库对外开放的范围里，分析用的汇总表都是去标识、聚合到粒度之后的指标，拿不到也不该拿到个人联系方式，直接查询会触碰合规红线。

可替代的分析是这样：如果市场部的目的是做人群运营，可以改从聚合维度切入，比如按会员等级、收货省份或访问渠道看人群规模和消费表现，再把筛出来的人群特征交给有权限的触达系统去对接，这样既满足运营诉求，也不碰敏感信息。具体想看哪个维度，可以再提一张取数单，我们按汇总口径给数。
