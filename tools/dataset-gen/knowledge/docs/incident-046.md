# 数据事故报告：2025-12-06 dim_region 关键字段为空

## 现象

`dim_region`（DIM-省份与大区维表）于 2025-12-06 经监控发现关键字段为空。核查确认，该表省份与大区的关键字段出现空值，导致下游在关联省份、大区维度时无法取到有效值，属关键字段为空类事故。事故自发现起持续 2 小时。

## 原因与影响范围

`dim_region` 本次问题的根本原因为上游业务系统字段改名，本表仍按旧字段取数，致使对应字段读取为空。经排查，本次事故未波及任何下游表，影响范围限于该表自身。

处理方面，数据平台组采取清理重复分区后重跑的方式进行修复。截至报告出具，该表已完成部分补数，剩余部分仍在跟进。
