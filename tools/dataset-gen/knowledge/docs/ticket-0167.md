# 取数需求单 REQ-2025-0167

## 需求

客服部于 2025-07-15 提出的需求，落在收货省份粒度的平均发货时长 `avg_ship_hours`（单位：小时）上，按日汇总，报告期为单月 2025-03，不设筛选条件。从背景看，客服部想摸清各省当月的发货时效表现，用以回应客户关于配送速度的咨询，并希望能长期留存这一视角。

## 结论

`dws_lgs_prov_ship_1d` 对应这一诉求，取数落在 `stat_date`、`receiver_province`、`ship_cnt`、`signed_cnt`、`avg_ship_hours` 这几个字段上，以 `stat_date` 限定 2025-03 后按收货省份铺开即可。分析时要特别注意口径：`avg_ship_hours` 是平均发货时长，不能跨行直接相加或求平均，若要得到一段时间或跨省的整体时效，应按发货单数加权重算；相对地，`ship_cnt` 与 `signed_cnt` 是可加和指标，汇总无碍。考虑到客服部的长期诉求，本次已交付，并沉淀为固定报表。
