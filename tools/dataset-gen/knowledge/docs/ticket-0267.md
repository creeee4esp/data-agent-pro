# 取数需求单 REQ-2025-0267

## 需求

市场部 2025-11-10 提的，想按小时分析，看看一天内不同时段的数据表现。单号 REQ-2025-0267，商品数据组接的。

## 结论

按小时的口径没法满足。DWS 汇总层最细只到天，所有汇总表的时间粒度就是按日、按周、按月，底层没有保留小时级的聚合，拿不到逐小时的指标。

可替代的分析是退到日粒度来看：想了解某段时间的波动，可以用日汇总表看逐日趋势，比如按天的下单、支付、访问指标，再结合周、月汇总观察更长周期的节奏。如果确实要做时段级的分析，那属于明细日志的加工范围，需要另立需求评估是否有合适的数据源和加工成本，不在当前汇总表的能力内。
