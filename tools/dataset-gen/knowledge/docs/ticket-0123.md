# 取数需求单 REQ-2025-0123

## 需求

客服部想要 2025-02 单月、按商品 SKU 粒度的日度访客数 `uv`，不加筛选，用来看看哪些单品到访的人多、咨询可能跟着多，好提前准备话术。

## 结论

`dws_traffic_sku_visit_1d` 是商品 SKU 粒度的按日访问汇总表，拿它来做刚好。字段取 `stat_date`、`sku_id`、`pv`、`uv`、`stay_seconds`，按 `stat_date` 限定在 2025-02。

这里得提醒客服部：访客数 `uv` 不能跨行相加。同一个人多天看同一个 SKU、或者看了多个 SKU，把日度 `uv` 加起来会把人重复算，所以别拿它累加出整月或多 SKU 的去重访客数，要去重得回访问明细。同表的 `pv`、`stay_seconds` 是可以相加的。

这次已经交付，并附上了 SQL，客服部后面想换 SKU 或时间段可以自己复用。
