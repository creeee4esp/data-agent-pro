# 取数需求单 REQ-2025-0039

## 需求

会员中心在 2025-02-15 提了需求 REQ-2025-0039，想要一级品类粒度的总停留秒数 `stay_seconds`，按周汇总，时间范围 2025-01，没有筛选条件。他们想看各一级品类当月的用户停留时长。

## 结论

`dws_traffic_cate1_visit_1w` 这张表能满足，由用户数据组接的单。按周取 2025-01 数据，维度用 `stat_date`、`category1_id`、`category1_name`，指标给 `stay_seconds` 总停留秒数。可加性提醒下：`pv` 和 `stay_seconds` 能跨行相加，按品类或按周汇总直接 SUM 就行；`uv` 不能跨行相加，是去重访客数，不同行加起来会重复，整体 `uv` 要回源去重。这次已交付，附 SQL 供需求方自助复用。
