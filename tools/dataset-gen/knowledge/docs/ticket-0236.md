# 取数需求单 REQ-2025-0236

## 需求

客服部在 2025-10-08 提出取数，关注 2025-02 至 2025-04 的已支付订单明细金额（`paid_amount`），希望按品牌粒度、月度口径看看各品牌连续三个月的成交走势，不设筛选条件。本单编号 REQ-2025-0236，处理人用户数据组。客服部想结合品牌成交波动辅助判断服务侧的关注重点。

## 结论

`dws_trade_brand_order_1m` 即 DWS-品牌粒度下单汇总（月）支撑这次取数，取 `stat_date`、`brand_name`、`order_cnt`、`item_qty`、`paid_amount`，报告期 `stat_date` 覆盖 2025-02 至 2025-04。

加和方面：`paid_amount` 可跨行相加，把各品牌、三个月的 `paid_amount` 汇总得到总额，或按月对比某品牌的走势，都是准确的，`item_qty` 同样可相加。要注意 `order_cnt` 不可跨行相加，涉及订单量时不要直接求和。

考虑到品牌走势需持续跟踪，本次已交付，并沉淀为固定报表。
