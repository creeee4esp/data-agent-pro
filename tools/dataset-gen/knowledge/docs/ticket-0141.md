# 取数需求单 REQ-2025-0141

## 需求

物流部希望了解 2025-04 至 2025-06 期间，各收货省份按周的已支付明细金额 `paid_amount`（元），不设筛选，目的是观察各省成交金额的周度走势，为仓配资源的动态调整提供参考。

## 结论

`dws_trade_prov_order_1w` 是收货省份粒度的按周下单汇总表，字段含 `stat_date`、`receiver_province`、`order_cnt`、`item_qty`、`paid_amount`，可直接满足需求。取数按 `stat_date` 限定在 2025-04 至 2025-06 的周区间。

从口径上分析，已支付明细金额 `paid_amount` 可跨行相加，把某省跨周累加成期间金额、或把各省汇成大盘，都成立，适合做趋势与占比。同表的 `item_qty` 同样可加；而下单数 `order_cnt` 不可相加，若物流一并关注单量，别跨周累加，以免订单重复计数。

本次已按一次性取数交付物流部。
