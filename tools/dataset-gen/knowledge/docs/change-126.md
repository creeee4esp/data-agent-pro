# 变更公告：调度时间调整（dim_sku）

## 变更说明

`dim_sku` 这次调整的是调度开始时间，由商品数据组发布，2025-10-20 生效。

从调度安排看，本次将该表作业开始时间由原 05:00 后移至 05:30。之所以顺延，是为了错开资源高峰，调整后产出时间相应后移约 30 分钟，但仍能在当日完成。

值得关注的是，`dim_sku` 作为商品维表被多处下游引用，时间后移意味着依赖它做维度关联的作业可能相应延后可用。建议使用方复核自身作业的触发时间与依赖设置，确保在 `dim_sku` 产出完成后再启动下游任务；若存在早于 05:30 读取本表的定时作业，请及时调整，以免关联到未更新的维度数据。
