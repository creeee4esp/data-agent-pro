# 指标说明：退款金额占比（退款金额占比）

## 计算公式

退款金额占比为派生指标，由退款金额与支付金额相除得到。

- 口径：refund_amount / pay_amt（同一时间范围）。
- 分子分母须取自同一时间范围，否则占比失真。
- 可加和：否。比率不能跨天相加或取平均。
- 更长周期：把 refund_amount 和 pay_amt 各自汇总后再相除。

## 取哪张表

退款金额占比需由分子分母现算，不单独存字段。

- 退款金额参考表：`dws_trade_prov_refund_1d`。
- 支付金额参考表：`dws_trade_prov_pay_1d`。
- 两表口径、时间范围须对齐后再相除。

## 来源与历史变化

退款金额占比由退款金额与支付金额派生而来，不独立存储。

- 历史变更：自上线以来未调整计算规则。
- 口径一致，可直接用于跨期趋势比较。
