# 取数需求单 REQ-2025-0131

## 需求

客服部现提出取数需求，拟获取 2025-03 至 2025-04 期间各品牌按周的下单数 `order_cnt`，不附加筛选条件，用于品牌成交规模的周度观察。

## 结论

经评估，`dws_trade_brand_order_1w` 系品牌粒度的按周下单汇总表，可满足本次要求。所取字段为 `stat_date`、`brand_name`、`order_cnt`、`item_qty`、`paid_amount`，时间范围依 `stat_date` 限定于 2025-03 至 2025-04。

需郑重提示：下单数 `order_cnt` 不可跨行相加，若将多周或多品牌的数值累加，将导致同一订单重复计数而使结论失真。如需更大范围的汇总口径，应采用可加和的购买件数 `item_qty` 与已支付明细金额 `paid_amount`。

本需求已按一次性取数交付客服部。
