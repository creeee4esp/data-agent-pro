# 取数需求单 REQ-2025-0047

## 需求

财务部在 2025-02-21 提了需求 REQ-2025-0047，想要品牌粒度的平均评分 `avg_rating`，按周汇总，时间范围 2025-02，没有筛选条件。他们想看各品牌当月的口碑评分。

## 结论

`dws_item_brand_review_1w` 这张表能满足，由交易数据组接的单。按周取 2025-02 数据，维度用 `stat_date`、`brand_name`，指标给 `avg_rating` 平均评分。这里要特别提醒：`avg_rating` 不能跨行相加，如果要跨品牌或跨周算整体平均评分，得用 `review_cnt` 作权重加权，直接把各行的 `avg_rating` 加起来没有意义；同表的 `review_cnt`、`good_cnt` 可以跨行相加。这次已交付，附 SQL 供需求方自助复用。
