# 取数需求单 REQ-2025-0088

## 需求

运营部希望了解 2025-01 至 2025-03 期间，各一级品类按周的购买件数 `item_qty`，不设筛选，目的是从销量角度观察一季度各品类的走势与季节性波动。

## 结论

`dws_trade_cate1_order_1w` 是一级品类粒度的按周下单汇总表，字段含 `stat_date`、`category1_id`、`category1_name`、`order_cnt`、`item_qty`、`paid_amount`，能直接满足需求。取数按 `stat_date` 限定在 2025-01 至 2025-03 的周区间。

从口径看，购买件数 `item_qty` 是可以跨行相加的指标，无论是把某个品类多周累加成季度销量，还是把多个品类汇成大盘总量，都成立，适合用来做趋势和同比。需要留意的是同表里的下单数 `order_cnt` 不可相加，如果运营后续想一并看单量，别把它跨周累加，否则会因订单重复计数而偏高。

本次已交付，并沉淀为固定报表供运营部查看。
