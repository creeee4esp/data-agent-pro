# 取数需求单 REQ-2025-0069

## 需求

会员中心在 2025-03-20 提了需求 REQ-2025-0069，想预测一下未来的销量，提前备货做计划。

## 结论

REQ-2025-0069 没法直接满足，由商品数据组评估后给的结论。原因是数据仓库里只有已经发生的历史汇总数据，没有预测模型，也没有外部的价格、活动、季节等预测因子，没法给出可靠的未来销量数字；硬做外推风险很大，容易误导备货决策。替代的做法是把历史规律讲清楚，为业务自己的判断提供依据：用 `dws_trade_cate1_order_1m` 看各一级品类按月的下单数和购买件数走势，识别增长或下滑的趋势和季节性波动。要说明这是历史趋势描述，不是预测结论。若后续要做预测，需要先立项引入建模能力和预测因子。
