# 取数需求单 REQ-2025-0063

## 需求

物流部于 2025-03-13 提出取数需求 REQ-2025-0063，要商品 SKU 粒度的平均评分 `avg_rating`，口径按月，时间范围 2025-01 至 2025-03，无筛选条件。诉求是看这三个月各 SKU 的口碑评分走势。

## 结论

`dws_item_sku_review_1m` 为本次用表，由流量数据组处理交付。维度取 `stat_date`、`sku_id`，指标输出 `avg_rating` 平均评分。可加性提示：`avg_rating` 不可跨行相加，跨 SKU 或跨月的整体平均评分须以 `review_cnt` 为权重加权，不能直接对该列求和；同表 `review_cnt`、`good_cnt` 可跨行相加。本需求已交付，并沉淀为固定报表。
