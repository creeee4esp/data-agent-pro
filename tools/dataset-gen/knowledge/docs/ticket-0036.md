# 取数需求单 REQ-2025-0036

## 需求

市场部在 2025-02-08 提了需求 REQ-2025-0036，想要仓库粒度的已签收单数 `signed_cnt`，按月汇总，时间范围 2025-01 至 2025-02，没有筛选条件。他们想看这两个月各仓库的签收情况。

## 结论

`dws_lgs_warehouse_ship_1m` 这张表能满足，由用户数据组接的单。按月取 2025-01 至 2025-02 数据，维度用 `stat_date`、`warehouse_id`、`warehouse_region`，指标给 `signed_cnt` 已签收单数。可加性提醒下：`ship_cnt` 和 `signed_cnt` 能跨行相加，按仓库或按月汇总直接 SUM 就行；`avg_ship_hours` 是平均发货时长，不能跨行相加，要整体平均得按单量加权。这次已交付一次性取数结果。
