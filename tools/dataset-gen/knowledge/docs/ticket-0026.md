# 取数需求单 REQ-2025-0026

## 需求

财务部于 2025-01-28 正式提出取数需求 REQ-2025-0026。需求方请求提供品牌粒度的好评数 `good_cnt`（4 星及以上），统计口径为按日汇总，时间范围为 2025-01，不设筛选条件。该数据用于按品牌核对口碑表现。

## 结论

`dws_item_brand_review_1d` 经确认为本次取数来源表，由数据平台组负责处理与交付。取数维度采用 `stat_date` 与 `brand_name`，输出指标为 `good_cnt` 好评数。关于可加性，特此说明：`review_cnt` 与 `good_cnt` 可跨行相加，按品牌或按日汇总时可直接求和；`avg_rating` 为平均评分，不可跨行相加，如需整体平均评分应以评价数为权重加权计算，不得对该列直接求和。本需求已交付一次性取数结果。
