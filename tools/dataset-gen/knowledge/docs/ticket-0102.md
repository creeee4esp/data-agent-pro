# 取数需求单 REQ-2025-0102

## 需求

会员中心想要 2025-02 至 2025-04、按会员等级看每日的已支付明细金额 `paid_amount`（元），不加筛选，用来看看不同等级会员的消费金额差距。

## 结论

`dws_trade_level_order_1d` 是会员等级粒度的按日下单汇总表，正好对口。字段取 `stat_date`、`member_level`、`order_cnt`、`item_qty`、`paid_amount`，按 `stat_date` 卡在 2025-02 到 2025-04 这三个月。

口径上，已支付明细金额 `paid_amount` 可以跨行相加，所以把某个等级多天的金额加成月度或季度合计、再按等级对比，都没问题；同表的 `item_qty` 也能加。要注意 `order_cnt` 不可相加，想看单量别直接累加，会重复计数。

这次已经交付，并沉淀成固定报表，会员中心后面可以持续看等级间的消费分布。
