# 取数需求单 REQ-2025-0139

## 需求

运营部希望了解 2025-03 至 2025-04 期间，各商品 SKU 按周的评价数 `review_cnt`，不设筛选，目的是观察单品的评价活跃度，为选品和内容运营提供口碑侧的参考。

## 结论

`dws_item_sku_review_1w` 是商品 SKU 粒度的按周评价汇总表，字段含 `stat_date`、`sku_id`、`review_cnt`、`good_cnt`、`avg_rating`，可直接满足需求。取数按 `stat_date` 限定在 2025-03 至 2025-04 的周区间。

从口径上分析，评价数 `review_cnt` 与好评数 `good_cnt` 都是可跨行相加的指标，把某 SKU 跨周累加成期间评价量、或把多个 SKU 汇总，都成立，适合做评价活跃度排序。需要留意平均评分 `avg_rating` 不可相加，若运营想看一批 SKU 的整体评分，应以 `review_cnt` 作权重重新加权，不能直接平均。
