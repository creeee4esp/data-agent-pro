# 取数需求单 REQ-2025-0279

## 需求

物流部在 2025-11-28 提出取数，关注 2025-05 至 2025-07 的访客数（`uv`），希望按访问用户粒度、月度访问口径查看三个月的访客规模，不设筛选条件。本单编号 REQ-2025-0279，处理人用户数据组。物流部想了解这一时期的访客体量基线。

## 结论

`dws_traffic_visitor_visit_1m` 即 DWS-访问用户粒度访问汇总（月）对应本次取数，取 `stat_date`、`visitor_id`、`pv`、`uv`、`stay_seconds`，报告期 `stat_date` 覆盖 2025-05 至 2025-07。

分析时要特别强调：`uv` 为去重访客数，不可跨行相加，既不能把各访问用户的 `uv` 相加，也不能把三个月的 `uv` 累加当作总访客规模，否则会把跨月重复来访的人算多次，建议逐月看或另按去重口径处理。`pv`、`stay_seconds` 可跨行相加，用于汇总浏览量与停留时长。
