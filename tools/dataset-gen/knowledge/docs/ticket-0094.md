# 取数需求单 REQ-2025-0094

## 需求

物流部希望了解 2025-02 至 2025-04 期间，各二级品类按周的已支付明细金额 `paid_amount`（元），不设筛选，目的是看清细分品类的成交金额走势，为货品调拨和备货节奏提供依据。

## 结论

`dws_trade_cate2_order_1w` 是二级品类粒度的按周下单汇总表，字段含 `stat_date`、`category2_id`、`category2_name`、`order_cnt`、`item_qty`、`paid_amount`，可直接满足需求。取数按 `stat_date` 限定在 2025-02 至 2025-04 的周区间。

口径上，已支付明细金额 `paid_amount` 是可跨行相加的，把某二级品类跨周累加成期间总额、或把多个品类汇总，都成立，适合做趋势和占比分析。同表的购买件数 `item_qty` 同样可加；但下单数 `order_cnt` 不可相加，若物流一并关注单量，别跨周累加，以免订单重复计数。

本次已按一次性取数交付物流部。
