# 取数需求单 REQ-2025-0127

## 需求

管理层希望了解 2025-03 至 2025-04 期间，各买家用户按月的支付笔数 `pay_cnt`，不设筛选，目的是观察用户支付频次的月度分布，为活跃度和复购策略提供参考。

## 结论

`dws_trade_user_pay_1m` 是买家用户粒度的按月支付汇总表，字段含 `stat_date`、`buyer_id`、`pay_cnt`、`pay_amt`，可直接满足需求。取数按 `stat_date` 限定在 2025-03 至 2025-04。

从口径上分析，支付笔数 `pay_cnt` 与支付金额 `pay_amt` 都是可跨行相加的指标，把某买家两个月累加成期间支付笔数、或把全体买家汇成大盘，都成立，适合做支付频次的用户分布与排序。管理层可据此识别高频支付用户群，再结合金额判断价值分层。
