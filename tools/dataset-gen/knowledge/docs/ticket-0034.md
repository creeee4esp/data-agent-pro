# 取数需求单 REQ-2025-0034

## 需求

物流部于 2025-02-06 正式提出取数需求 REQ-2025-0034。需求方请求提供访问用户粒度的浏览量 `pv`，统计口径为按周汇总，时间范围为 2025-01 至 2025-02，不设筛选条件。该数据用于观察这两个月各访客的浏览活跃度。

## 结论

`dws_traffic_visitor_visit_1w` 经确认为本次取数来源表，由商品数据组负责处理与交付。取数维度采用 `stat_date` 与 `visitor_id`，输出指标为 `pv` 浏览量。关于可加性，特此说明：`pv` 与 `stay_seconds` 可跨行相加，按访客或按周汇总时可直接求和；`uv` 为去重访客数，不可跨行相加，跨行相加将造成重复计数，如需整体 `uv` 须回源去重。本需求已交付，并附 SQL 供需求方自助复用。
