# 指标说明：平均停留时长（平均停留时长）

## 计算公式

平均停留时长为派生指标，口径是 stay_seconds / pv，即用总停留秒数除以浏览量，得到平均每次访问停留多少秒。最容易误用的一点是分母用错：分母是浏览量 pv（访问次数），不是去重访客数，若误用访客数会把口径算成人均停留而非单次停留。它是比率，不可加和，要算更长周期的平均停留时长，得把 stay_seconds 和 pv 各自汇总后再相除，不能对各期平均值取平均。

## 取哪张表

平均停留时长需由分子分母现算，不单独存字段。参考表为 `dws_traffic_cate1_visit_1d`，从中取 stay_seconds 与 pv 相除即得当日该品类的平均停留时长。要注意分子分母取自同一时间范围、同一维度，跨维度混取会导致口径错位。

## 来源与历史变化

平均停留时长由总停留秒数与浏览量派生而来，不独立存储。该指标自上线以来未调整计算规则，口径一致，可直接用于跨期趋势比较。
