# 取数需求单 REQ-2025-0107

## 需求

管理层希望分析用户的搜索词和加购行为，想看看大家常搜什么、加购转化如何，以此指导搜索运营和商品投放。

- 诉求一：热门搜索词分布
- 诉求二：加购次数与加购转化

## 结论

该需求当前无法满足，原因如下：

- 数据仓库没有对应的行为日志，现有汇总表覆盖的是交易、支付、退款、访问、评价、发货等主题，既没有搜索词日志，也没有加购事件记录
- 因此搜索词和加购相关的指标无法产出

可替代的分析方向：

- 用访问类汇总看品类和单品的浏览热度，间接反映用户兴趣
- 用交易类汇总看下单与支付转化，衡量后端成交效率
- 若必须要搜索与加购口径，属于需接入埋点日志、新建数据模型的需求，须另行立项，不在本次取数范围内
