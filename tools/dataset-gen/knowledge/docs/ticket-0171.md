# 取数需求单 REQ-2025-0171

## 需求

客服部于 2025-07-22 提出的需求，围绕买家用户粒度的已支付订单明细金额 `paid_amount`（单位：元）展开，按月汇总，报告期为单月 2025-03，不设筛选条件。从沟通看，客服部希望长期掌握各买家的成交金额分布，以便结合客诉情况识别高价值用户，所以希望把这份数据固化下来。

## 结论

`dws_trade_user_order_1m` 对应这一诉求，取数落在 `stat_date`、`buyer_id`、`order_cnt`、`item_qty`、`paid_amount` 这几个字段上，以 `stat_date` 限定 2025-03 后按 `buyer_id` 铺开即可。分析时要留意口径差异：`paid_amount` 与 `item_qty` 是可加和指标，跨用户求和成立；而 `order_cnt` 是去重下单数，不能跨行累加，若把各用户的 `order_cnt` 相加会出现重复计数。考虑到客服部的长期需求，本次已交付，并沉淀为固定报表。
