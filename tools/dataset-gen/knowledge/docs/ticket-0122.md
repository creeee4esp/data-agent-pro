# 取数需求单 REQ-2025-0122

## 需求

市场部希望了解 2025-02 至 2025-04 期间，各品牌按日的平均评分 `avg_rating`，不设筛选，目的是从满意度角度观察各品牌口碑的日度波动，辅助品牌合作与营销决策。

## 结论

`dws_item_brand_review_1d` 是品牌粒度的按日评价汇总表，字段含 `stat_date`、`brand_name`、`review_cnt`、`good_cnt`、`avg_rating`，可直接满足需求。取数按 `stat_date` 限定在 2025-02 至 2025-04。

从口径上分析，平均评分 `avg_rating` 是一个不可跨行相加的指标，既不能把多天或多品牌的评分直接累加，也不能对各行取简单平均，否则会忽略评价量差异导致偏差。如果市场部想看某品牌一段时间的整体评分，应以评价数 `review_cnt` 作权重重新加权。同表的 `review_cnt`、`good_cnt` 可跨行相加，用来衡量声量没有问题。

本次已按一次性取数交付市场部。
