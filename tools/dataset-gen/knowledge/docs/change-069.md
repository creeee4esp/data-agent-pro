# 变更公告：新表上线（dws_traffic_cate1_visit_1w）

## 变更说明

`dws_traffic_cate1_visit_1w`（DWS-一级品类粒度访问汇总（周））上线，补足了一级品类周度访问汇总的缺口。

### 背景与内容

此前做一级品类的周度访问趋势，往往得从访问明细临时聚合，既慢又容易口径不一致。新表直接从 `dwd_traffic_visit_di` 加工而来，把一级品类维度的周度访问数据沉淀下来，分析时可直接取用。

### 生效、影响与动作

表自 `2025-05-29` 起正式产出。作为新增产出，它不改动任何现有表的结构与数据。原先自行聚合一级品类周度访问的同学，建议改接 `dws_traffic_cate1_visit_1w`，减少重复加工。
