# 取数需求单 REQ-2025-0179

## 需求

市场部于 2025-07-31 提出的需求，落在 SKU 粒度的好评数 `good_cnt`（4 星及以上）上，按日汇总，报告期区间为 2025-03 至 2025-05，不设筛选条件。从沟通看，市场部希望结合这段时间的好评表现评估重点 SKU 的口碑积累，并计划后续自己反复拉取，所以要了可复用的取数口径。

## 结论

`dws_item_sku_review_1d` 对应这一诉求，取数落在 `stat_date`、`sku_id`、`review_cnt`、`good_cnt`、`avg_rating` 这几个字段上，以 `stat_date` 限定 2025-03 至 2025-05 后按 `sku_id` 铺开即可。分析时需区分指标口径：`good_cnt` 与 `review_cnt` 是可加和指标，跨日或跨 SKU 求和都成立；而 `avg_rating` 是平均评分，不能跨行直接相加，若要整体平均须按评价数加权重算。本次已交付，并附 SQL 供市场部自助复用。
