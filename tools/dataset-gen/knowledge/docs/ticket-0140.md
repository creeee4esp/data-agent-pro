# 取数需求单 REQ-2025-0140

## 需求

商品部希望查看 2025-02 单月、各收货省份按月的已支付明细金额 `paid_amount`（元），不设筛选，目的是从成交金额角度了解各省的贡献分布，为区域选品与货品铺设提供依据。

## 结论

`dws_trade_prov_order_1m` 是收货省份粒度的按月下单汇总表，字段含 `stat_date`、`receiver_province`、`order_cnt`、`item_qty`、`paid_amount`，可直接满足需求。取数按 `stat_date` 限定在 2025-02。

从口径上分析，已支付明细金额 `paid_amount` 是可跨行相加的，把各省金额汇成全国大盘、或排出省份金额名次，都成立。同表的购买件数 `item_qty` 同样可加；而下单数 `order_cnt` 不可相加，若商品部一并关注单量，别跨省或跨期累加，以免订单重复计数，应逐行看或改用可加指标。

本次已按一次性取数交付商品部。
