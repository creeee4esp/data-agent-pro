# 取数需求单 REQ-2025-0100

## 需求

运营部希望查看 2025-01 单月、按买家用户粒度的周度退款金额 `refund_amount`（元），不设筛选，目的是识别退款金额偏高的用户群，为售后策略和用户分层提供线索。

## 结论

`dws_trade_user_refund_1w` 是买家用户粒度的按周退款汇总表，字段含 `stat_date`、`buyer_id`、`refund_cnt`、`refund_amount`，能直接满足需求。取数按 `stat_date` 限定在 2025-01 的周区间，按买家输出退款金额。

从口径上看，退款金额 `refund_amount` 与退款笔数 `refund_cnt` 都是可跨行相加的指标，所以把某买家整月各周退款累加、或把全体买家汇成大盘总额，都成立，适合做用户侧的退款规模排序与分层。运营部可据此先锁定头部退款用户，再结合退款原因做深入分析。
