# 变更公告：新表上线（dws_trade_cate1_order_1w）

## 变更说明

`dws_trade_cate1_order_1w`（DWS-一级品类粒度下单汇总（周））上线了，做一级品类周度下单分析的同学可以用起来。

### 这表是干嘛的

它从 `dwd_trade_order_detail_di` 加工而来，把一级品类维度的周度下单数据沉淀成一张汇总表。以前要看一级品类的周度下单趋势得自己从明细聚合，现在直接查这张就行，省事也更统一。

### 生效与影响

从 `2025-02-22` 起产出。属于新增表，不动任何现有表。原来自己聚合的同学，建议改接 `dws_trade_cate1_order_1w`。

物流数据组发布。
