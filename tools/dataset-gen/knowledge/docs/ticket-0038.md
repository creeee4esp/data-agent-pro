# 取数需求单 REQ-2025-0038

## 需求

管理层在 2025-02-14 提了需求 REQ-2025-0038，想算一下利润、毛利，看看各块业务到底赚不赚钱。

## 结论

REQ-2025-0038 没法满足，由用户数据组评估后给的结论。原因是仓库里没有成本数据，进货成本、履约成本这些都没有入仓，利润和毛利是收入减成本，缺了成本这一半，算出来的任何数字都不可信，所以这次不做硬算。替代的思路是先把收入侧的结构讲清楚：用 `dws_trade_cate1_order_1d` 看各一级品类已支付订单的明细金额分布，用 `dws_trade_channel_pay_1d` 看各支付渠道的支付金额结构，帮助判断收入集中在哪里。等后续成本数据接入，再补利润口径。需说明这些只是收入侧的分析，替代不了真正的利润核算。
