# 物流时效月报：2025-09

## 概览

物流时效月报 2025-09 期覆盖六大仓库大区与四家承运商，发货单量合计 1,371 单。

- 发货量最高的大区是华东，2025-09 共发货 440 单，平均发货 25.20 小时、平均配送 79.48 小时。
- 发货最快的大区是华南，平均发货 21.68 小时；发货最慢的是华东，平均发货 25.20 小时。
- 配送最快的大区是西南，平均配送 77.75 小时；配送最慢的是西北，平均配送 90.07 小时。
- 承运商签收率介于 89.55%（zto）与 91.83%（yto）之间。

## 结论

结论基于 2025-09 物流时效月报给出的数字。

- 华东发货量最大（440 单）但平均发货最慢（25.20 小时），建议优先核查华东仓的发货环节。
- 西北平均配送 90.07 小时，为六大区最慢，是配送时效的重点关注对象。
