# 取数需求单 REQ-2025-0029

## 需求

管理层在 2025-01-31 提了需求 REQ-2025-0029，想要一级品类粒度的访客数 `uv`，按日汇总，时间范围 2025-01，没有筛选条件。他们想看各一级品类当月的访客规模。

## 结论

`dws_traffic_cate1_visit_1d` 这张表能满足，由数据平台组接的单。按日取 2025-01 数据，维度用 `stat_date`、`category1_id`、`category1_name`，指标给 `uv` 访客数。可加性得提醒：`uv` 不能跨行相加，它是去重访客数，把不同品类或不同天的 `uv` 加起来会重复计数，要整体 `uv` 得回源去重；同表 `pv`、`stay_seconds` 可以跨行相加。这次已交付，附 SQL 供需求方自助复用。
