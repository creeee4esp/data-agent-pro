# 取数需求单 REQ-2025-0162

## 需求

管理层于 2025-07-12 提出的需求，落在 SKU 粒度的评价数 `review_cnt` 上，按月汇总，报告期为单月 2025-02，不设筛选条件。从沟通看，管理层想掌握年初各 SKU 的评价规模，作为商品运营的一个基础观察口径。

## 结论

`dws_item_sku_review_1m` 对应这一诉求，取数落在 `stat_date`、`sku_id`、`review_cnt`、`good_cnt`、`avg_rating` 这几个字段上，以 `stat_date` 限定 2025-02 后按 `sku_id` 铺开即可。分析时需区分指标口径：`review_cnt` 与 `good_cnt` 是可加和指标，跨 SKU 求和没有问题；而 `avg_rating` 是平均评分，不能跨行直接相加，若要整体平均须按评价数加权重算。本次已交付一次性取数结果。
