# 变更公告：提醒：备份 / 副本表列名与正表不一致（pay_order_20250519）

## 变更说明

`pay_order_20250519` 是一张带日期的备份表，它的列名与正表并不一致，这里专门提醒一下，避免取数时踩坑。

### 问题细节

正表里的订单主键列叫 `order_id`，而这张备份把同一列命名成了 `ord_id`。两者指向的是同一含义，但名字不同。若直接拿写正表的 SQL 去查备份，就会因为找不到 `order_id` 而报错；反过来凭记忆在正表上写 `ord_id` 同样会失败。

### 影响与动作

影响的是所有引用 `pay_order_20250519` 的查询。自 `2025-02-07` 起，请以本提醒为准：查备份时把列名改写成 `ord_id`，正式分析仍以正表及其 `order_id` 为准，尽量不要长期依赖该备份。
