# 取数需求单 REQ-2025-0022

## 需求

管理层于 2025-01-23 提出取数需求 REQ-2025-0022，要一级品类粒度已支付订单的明细金额 `paid_amount`（单位元），口径按日，时间范围 2025-01，无筛选条件。诉求是看各一级品类当月的成交金额贡献。

## 结论

`dws_trade_cate1_order_1d` 为本次用表，由用户数据组处理交付。维度取 `stat_date`、`category1_id`、`category1_name`，指标输出 `paid_amount` 已支付订单的明细金额。可加性提示：`item_qty`、`paid_amount` 可跨行相加，按品类或按日汇总可直接 SUM；`order_cnt` 不可跨行相加，为订单去重计数。本需求已交付，并沉淀为固定报表。
