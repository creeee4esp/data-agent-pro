# 数据事故报告：2025-10-08 ads_pay_channel_monthly 关键字段为空

## 现象

`ads_pay_channel_monthly`（ADS-支付渠道月度报表）在 2025-10-08 被发现关键字段为空。从现象上追溯，支付渠道月度报表中承载维度信息的关键字段出现空值，按支付渠道拆分的口径随之无法落地，下游在使用该维度时读到空白。问题从发现到处置共持续 3 小时。

## 原因与影响范围

`ads_pay_channel_monthly` 的空值源头，经分析可归结到关联维表时维表未更新。本表在关联过程中未能匹配到有效维度值，对应字段因此落空，这是此类问题的典型路径。就影响范围而言，本次事故并未波及任何下游表，扩散被及时遏制。

处理层面，流量数据组采取重跑当天任务并补数的方式，使空值字段重新填充正确。目前数据已完成补数，报表恢复可用状态。
