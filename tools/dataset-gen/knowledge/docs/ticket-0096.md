# 取数需求单 REQ-2025-0096

## 需求

客服部现提出取数需求，拟获取 2025-04 期间各一级品类按日的访客数 `uv`，不附加筛选条件，用于观察品类页面的到访规模。

## 结论

经评估，`dws_traffic_cate1_visit_1d` 系一级品类粒度的按日访问汇总表，可满足本次要求。所取字段为 `stat_date`、`category1_id`、`category1_name`、`pv`、`uv`、`stay_seconds`，时间范围依 `stat_date` 限定于 2025-04。

需郑重提示：访客数 `uv` 不可跨行相加，同一访客多日或跨品类到访将被重复计数，故不得将日度 `uv` 简单累加为整月或大盘去重访客数，如需去重口径，应回访问明细重新计算。同表的浏览量 `pv` 与总停留秒数 `stay_seconds` 可跨行相加。

本需求已交付，附 SQL 供需求方自助复用。
