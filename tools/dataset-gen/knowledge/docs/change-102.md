# 变更公告：表注释修正（log_visit）

## 变更说明

`log_visit` 这次修正的是表注释本身。此前该表的注释存在描述不准确的问题，容易让使用方误判其数据范围，本次将其正确注释修订为“商品页访问日志”，由流量数据组发布，2025-08-26 生效。

从影响面看，这是一次元数据层面的修正，表结构、字段和历史数据都不变，取数结果不受影响。真正变化的是对表用途的理解：`log_visit` 记录的是商品页的访问日志，使用方在挑选数据源时应据此判断其适用场景，不要再按旧注释的含义去理解。

使用方无需调整现有 SQL，建议生效后刷新元数据缓存，使最新注释正确展示，避免后续分析沿用错误的表用途认知。
