# 表说明：dws_trade_cate1_order_1m（DWS-一级品类粒度下单汇总（月））

## 概述

`dws_trade_cate1_order_1m` 为一级品类维度的下单月度汇总表，当前共 84 行。该表以统计月与一级品类为粒度，对下单行为按月聚合，其中 `stat_date` 存储各月月初日期，用以标识统计所属月份。数据源自交易明细表 `dwd_trade_order_detail_di`，统计口径与同家族的日表、周表一致，仅聚合周期不同。

## 字段

- `stat_date`：统计月，取值为月初日期，代表整月而非具体某日，按月筛选时须以月初日期作为匹配值。
- `category1_id`：一级品类ID，与 `stat_date`、`category1_name` 共同构成行粒度，用于关联与分组时建议优先使用该 ID。
- `category1_name`：一级品类名称，供展示与排序使用。
- `order_cnt`：下单数，为当月去重后的订单计数，可按月累加求区间总量。
- `item_qty`：购买件数，包含未支付订单，统计销量时须注意该口径偏大。
- `paid_amount`：已支付订单的明细金额（元），仅累计已支付部分，不应等同于当月下单总额。

## 上下游

数据来源为交易明细表 `dwd_trade_order_detail_di`，加工时按月初日期、`category1_id` 与 `category1_name` 分组聚合写入本表。当前无登记在册的下游表，如需更高层级汇总，通常直接基于本表再行聚合。

## 使用注意

该表适用于一级品类的月度趋势分析、月度同比环比以及品类月度排名等场景，因每月每品类仅一行，查询效率较高。若需日或周粒度数据，应改用对应的日表或周表。该家族当前未发现同名的备份表、分表或测试表，取数时直接使用本表即可，无需额外甄别噪声表。
