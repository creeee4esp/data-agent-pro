# 取数需求单 REQ-2025-0199

## 需求

市场部于 2025-08-23 正式提出取数申请，需求对象为品牌粒度的好评数 `good_cnt`（4 星及以上），按日汇总，报告期区间为 2025-07 至 2025-08，不附加任何筛选条件。该数据拟用于评估各品牌在这两个月的好评积累情况。

## 结论

`dws_item_brand_review_1d` 为本需求推荐用表，取数涉及 `stat_date`、`brand_name`、`review_cnt`、`good_cnt`、`avg_rating` 等字段，以 `stat_date` 限定 2025-07 至 2025-08 后按品牌输出即可。需提请注意：`good_cnt` 与 `review_cnt` 为可加和指标，跨日或跨品牌求和均成立；而 `avg_rating` 系平均评分，不得跨行直接相加，整体平均须按评价数加权重算。本需求已交付，并随附 SQL 供市场部自助复用。
