# 取数需求单 REQ-2025-0056

## 需求

管理层在 2025-03-04 提了需求 REQ-2025-0056，想要商品 SKU 粒度的评价数 `review_cnt`，按周汇总，时间范围 2025-03，没有筛选条件。他们想看各 SKU 当月的评价积累。

## 结论

`dws_item_sku_review_1w` 这张表能满足，由交易数据组接的单。按周取 2025-03 数据，维度用 `stat_date`、`sku_id`，指标给 `review_cnt` 评价数。可加性提醒下：`review_cnt` 和 `good_cnt` 能跨行相加，按 SKU 或按周汇总直接 SUM 就行；`avg_rating` 是平均评分，不能跨行相加，要整体平均得按评价数加权算。这次已交付，附 SQL 供需求方自助复用。
