# 取数需求单 REQ-2025-0035

## 需求

物流部于 2025-02-06 正式提出取数需求 REQ-2025-0035。需求方请求提供二级品类粒度的下单数 `order_cnt`，统计口径为按月汇总，时间范围为 2025-02，不设筛选条件。该数据用于观察各二级品类当月的下单规模。

## 结论

`dws_trade_cate2_order_1m` 经确认为本次取数来源表，由交易数据组负责处理与交付。取数维度采用 `stat_date`、`category2_id` 与 `category2_name`，输出指标为 `order_cnt` 下单数。关于可加性，特此说明：`item_qty` 与 `paid_amount` 可跨行相加，按二级品类汇总时可直接求和；`order_cnt` 为订单去重计数，不可跨行相加，跨行相加将造成重复，如需整体口径应回源重新统计。本需求已交付，并沉淀为固定报表。
