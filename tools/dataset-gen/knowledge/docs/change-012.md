# 变更公告：调度时间调整（dws_trade_user_refund_1m）

## 变更说明

`dws_trade_user_refund_1m` 的调度开始时间从 `02:30` 提前到 `02:00`，这里说明一下调整的来龙去脉。

### 调整原因与内容

从近期运行看，该表的上游退款明细在凌晨已较早就绪，而原先 `02:30` 的开始时间让产出偏晚、挤占了下游窗口。为给下游留出更充裕的缓冲，调度开始时间统一提前到 `02:00`。

### 生效、影响与动作

调整自 `2025-02-01` 起生效。产出口径和数据内容不变，只是出数时间略有提前。依赖该表的下游任务无需改动，但可留意产出时间前移带来的调度联动。
