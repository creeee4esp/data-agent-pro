# 取数需求单 REQ-2025-0032

## 需求

物流部在 2025-02-03 提了需求 REQ-2025-0032，想要品牌粒度的评价数 `review_cnt`，按日汇总，时间范围 2025-01，没有筛选条件。他们想看各品牌当月每天的评价量变化。

## 结论

`dws_item_brand_review_1d` 这张表能满足，由交易数据组接的单。按日取 2025-01 数据，维度用 `stat_date`、`brand_name`，指标给 `review_cnt` 评价数。可加性提醒下：`review_cnt` 和 `good_cnt` 能跨行相加，按品牌或按日汇总直接 SUM 就行；`avg_rating` 是平均评分，不能跨行相加，要整体平均得按评价数加权算。这次已交付，附 SQL 供需求方自助复用。
