# 数据事故报告：2025-01-23 dws_trade_user_refund_1m 数据重复

## 现象

`dws_trade_user_refund_1m`（DWS-买家用户粒度退款汇总（月））在 2025-01-23 被发现有数据重复。当天核对的时候注意到买家用户粒度的月度退款汇总里出现了重复记录，同一用户的退款被算了不止一次。这个问题从发现到搞定前后持续了 1 小时。

## 原因与影响范围

`dws_trade_user_refund_1m` 这次重复，说到底是上游同步重复投递造成的，同一批数据被投了两遍，汇总时就叠出了重复。好在影响范围不大，没有下游表受到波及。

处理上我们修复 SQL 后回刷了近 7 天的数据，把重复的部分清掉重新算了一遍。现在数据已经补好了，结果恢复正常。这次由流量数据组跟进处理。
