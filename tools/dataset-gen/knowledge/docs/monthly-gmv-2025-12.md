# 交易 GMV 月报：2025-12

## 概览

2025-12 交易 GMV 为 4,059,800.50 元，环比 -18.2%，较上月高点有所回落但仍处年内偏高水平。本月支付订单数 1,687，支付买家数 849，客单价（GMV/支付订单数）2,406.52 元；单日最高落在 2025-12-12，当天 GMV 272,529.70 元。
