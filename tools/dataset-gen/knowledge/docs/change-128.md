# 变更公告：指标计算规则说明（item_qty）

## 变更说明

`item_qty` 这次明确一下口径，免得大家取数取错，2025-10-28 生效，交易数据组发布。

说明是这样的：`item_qty` 这个购买件数是含未支付订单的，也就是说只要下单了就算进去，不管付没付款。所以如果你要的是已支付的件数，别直接用这个指标，请改用 ADS 品类报表里对应的口径。

这只是口径说明，底层数据加工逻辑没改，历史数据也不回刷。影响的是所有用 `item_qty` 统计件数的查询和报表。麻烦大家对一下自己的口径：要全量下单件数就用 `item_qty`，要已支付件数就走 ADS 品类报表，别混着用。
