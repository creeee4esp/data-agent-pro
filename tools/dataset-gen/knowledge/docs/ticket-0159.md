# 取数需求单 REQ-2025-0159

## 需求

市场部于 2025-07-07 正式提出取数申请，需求对象为收货省份粒度的购买件数 `item_qty`，按周汇总，报告期为 2025-06，不附加任何筛选条件。该数据拟用于观察当月各收货省份的销量分布。

## 结论

`dws_trade_prov_order_1w` 为本需求推荐用表，取数涉及 `stat_date`、`receiver_province`、`order_cnt`、`item_qty`、`paid_amount` 等字段，以 `stat_date` 限定 2025-06 后按收货省份与周输出即可。需提请注意：`item_qty` 与 `paid_amount` 为可加和指标，跨周或跨省求和均成立；而 `order_cnt` 系去重下单数，不得跨行累加，各省相加不等于全国总下单数。本需求已交付，并随附 SQL 供市场部自助复用。
