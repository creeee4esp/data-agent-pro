# 数据事故报告：2025-11-14 ads_trade_cate1_sales_monthly 计算结果偏差

## 现象

`ads_trade_cate1_sales_monthly`（ADS-一级品类月度销售额）在 2025-11-14 被发现计算结果偏差。当天核对时发现一级品类月度销售额的数值跟预期对不上，存在明显偏差。这个问题从发现到处理完持续了 8 小时。

## 原因与影响范围

`ads_trade_cate1_sales_monthly` 这次偏差的原因是维表 SCD 处理错误，关联维度时取数不准，算出来的销售额就跟着偏了。影响面不大，没有下游表被牵连。

处理上我们修复 SQL 后回刷了近 7 天的数据，把偏差期间可能受影响的分区一起重算了一遍。现在数据已经补好了，结果恢复正常。这次由物流数据组跟进。
