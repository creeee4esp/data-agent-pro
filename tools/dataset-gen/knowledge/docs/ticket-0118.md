# 取数需求单 REQ-2025-0118

## 需求

市场部希望查看 2025-05 单月、按买家用户粒度的日度退款笔数 `refund_cnt`，不设筛选，目的是从退款行为角度识别哪些用户退款频繁，为后续的用户运营和风险识别提供线索。

## 结论

`dws_trade_user_refund_1d` 是买家用户粒度的按日退款汇总表，字段含 `stat_date`、`buyer_id`、`refund_cnt`、`refund_amount`，可直接满足需求。取数按 `stat_date` 限定在 2025-05，按买家输出退款笔数。

从口径上看，退款笔数 `refund_cnt` 与退款金额 `refund_amount` 都是可跨行相加的指标，把某买家整月的退款笔数累加、或把全体买家汇成大盘，都成立，适合做退款频次的用户排序。市场部可据此先圈出高频退款用户，再结合退款金额判断影响程度。

本次已按一次性取数交付市场部。
