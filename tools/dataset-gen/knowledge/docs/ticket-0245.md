# 取数需求单 REQ-2025-0245

## 需求

财务部在 2025-10-21 提出取数，关注 2025-04 至 2025-05 的支付笔数（`pay_cnt`），希望按收货省份粒度、日度支付口径查看，并且只看山东省。本单编号 REQ-2025-0245，处理人用户数据组。财务部想单独盯一下山东省这两个月的日度支付节奏。

## 结论

`dws_trade_prov_pay_1d` 即 DWS-收货省份粒度支付汇总（日）对应本次取数，取 `stat_date`、`receiver_province`、`pay_cnt`、`pay_amt`，报告期 `stat_date` 覆盖 2025-04 至 2025-05，并按 `receiver_province` 只保留山东省的行。

加和方面这张表很直观：`pay_cnt` 与 `pay_amt` 都可跨行相加，把山东省这两个月的 `pay_cnt` 逐日累加得到区间总支付笔数是准确的，`pay_amt` 同理可汇总出区间支付金额。

考虑到财务对该省份有持续跟踪的诉求，本次已交付，并沉淀为固定报表。
