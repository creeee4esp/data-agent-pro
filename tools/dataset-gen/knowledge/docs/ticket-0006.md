# 取数需求单 REQ-2025-0006

## 需求

商品部于 2025-01-07 提出取数需求 REQ-2025-0006，要访问用户粒度的访客数 `uv`，口径按月，时间范围 2025-01，无筛选条件。诉求是掌握当月整体访客规模。

## 结论

`dws_traffic_visitor_visit_1m` 为本次用表，由商品数据组处理交付。维度取 `stat_date`、`visitor_id`，指标输出 `uv` 访客数。关键提示：`uv` 不能跨行相加，它是去重访客数，把不同访客行相加会重复计数，若要整体 `uv` 必须回源去重；同表 `pv`、`stay_seconds` 可跨行相加。本需求已交付，附 SQL 供需求方自助复用。
