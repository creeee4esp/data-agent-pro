# 取数需求单 REQ-2025-0078

## 需求

管理层希望看到 2025-01 单月各一级品类按日的浏览量 `pv`，不加筛选，意图是观察年初各品类流量的起势节奏，为后续资源投放做方向判断。

## 结论

`dws_traffic_cate1_visit_1d` 是一级品类粒度的按日访问汇总表，字段有 `stat_date`、`category1_id`、`category1_name`、`pv`、`uv`、`stay_seconds`，能直接回答这个需求。取数时把 `stat_date` 限定在 2025-01，按品类输出每天的 `pv` 即可。

从口径上看，浏览量 `pv` 和总停留秒数 `stay_seconds` 都是可以跨行相加的，所以把一个品类整月的 `pv` 加总、或者把各品类再汇成大盘都成立。但访客数 `uv` 不可相加——同一个访客可能多天到访，跨行累加会把人重复计数，若管理层想看整月去重访客规模，需要回到访问明细重新去重，不能拿日度 `uv` 简单求和。

本次已交付，并沉淀为固定报表。
