# 变更公告：提醒：备份 / 副本表列名与正表不一致（item_review_20250106）

## 变更说明

`item_review_20250106` 系正表的备份副本，经核查其列名与正表存在不一致，现予通告，自 2025-09-23 起生效，由商品数据组发布。

具体差异为：正表中的列名为 `user_id`，而副本表 `item_review_20250106` 中对应列名为 `usr_id`。两列记录内容一致，仅命名不同，直接套用正表 SQL 将因列不存在而报错。

影响范围为所有直接访问该备份副本的查询、脚本及临时分析。请使用方在引用 `item_review_20250106` 时，将 `user_id` 改写为 `usr_id`，并自查既有作业是否因列名差异而失败或取数为空；如无必要，建议优先使用正表取数，以免口径混淆。
