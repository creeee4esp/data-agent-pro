# 变更公告：表注释修正（lgs_shipment）

## 变更说明

`lgs_shipment` 这次修正的是表注释。此前该表的注释描述不够准确，容易让使用方误判其数据内容，本次将正确注释定为“物流发货单表”，由用户数据组发布，2025-12-27 生效。

从影响面看，这属于元数据层面的修正，表结构、字段和历史数据都不变，取数结果不受影响。真正变化的是对表用途的理解：`lgs_shipment` 记录的是物流发货单信息，使用方在挑选数据源时应据此判断其适用场景，不要再沿用旧注释的含义。

使用方无需调整现有 SQL，建议生效后刷新元数据缓存，使最新注释正确展示，避免后续分析基于错误的表用途认知。
