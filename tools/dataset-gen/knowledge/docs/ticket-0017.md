# 取数需求单 REQ-2025-0017

## 需求

物流部在 2025-01-17 提了需求 REQ-2025-0017，想要退款原因粒度的退款金额 `refund_amount`（单位元），按周汇总，时间范围 2025-01，没有筛选条件。他们想看看各退款原因当月的退款金额分布。

## 结论

`dws_trade_reason_refund_1w` 这张表就能满足，由商品数据组接的单。按周取 2025-01 数据，维度用 `stat_date`、`refund_reason`，指标给 `refund_amount` 退款金额。可加性这次比较简单，`refund_cnt` 和 `refund_amount` 都能跨行相加，按退款原因或按周汇总直接 SUM 就行。这次已交付一次性取数结果。
