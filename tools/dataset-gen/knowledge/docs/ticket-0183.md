# 取数需求单 REQ-2025-0183

## 需求

财务部于 2025-08-05 提出的需求，围绕 SKU 粒度的下单数 `order_cnt` 展开，按周汇总，报告期为 2025-04，不设筛选条件。从背景看，财务部希望按 SKU 观察当月的下单活跃度，并打算后续自己复用，所以要了可自助执行的取数口径。

## 结论

`dws_trade_sku_order_1w` 对应这一诉求，取数落在 `stat_date`、`sku_id`、`order_cnt`、`item_qty`、`paid_amount` 这几个字段上，以 `stat_date` 限定 2025-04 后按 `sku_id` 与周铺开即可。分析时要留意口径差异：`order_cnt` 是去重下单数，不能跨行累加，跨周汇总会重复计数，若要看一段时间的总下单数须回明细重算；而 `item_qty` 与 `paid_amount` 是可加和指标，求和无碍。本次已交付，并附 SQL 供财务部自助复用。
