# 取数需求单 REQ-2025-0170

## 需求

运营部于 2025-07-22 正式提出取数申请，需求对象为收货省份粒度的发货单数 `ship_cnt`，按周汇总，报告期区间为 2025-05 至 2025-06，不附加任何筛选条件。该数据拟用于观察各收货省份两个月的发货规模分布。

## 结论
