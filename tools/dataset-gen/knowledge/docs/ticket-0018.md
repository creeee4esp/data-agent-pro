# 取数需求单 REQ-2025-0018

## 需求

管理层于 2025-01-19 提出取数需求 REQ-2025-0018，要二级品类粒度已支付订单的明细金额 `paid_amount`（单位元），口径按月，时间范围 2025-01，无筛选条件。诉求是看各二级品类当月的成交金额贡献。

## 结论

`dws_trade_cate2_order_1m` 为本次用表，由数据平台组处理交付。维度取 `stat_date`、`category2_id`、`category2_name`，指标输出 `paid_amount` 已支付订单的明细金额。可加性提示：`item_qty`、`paid_amount` 可跨行相加，按二级品类汇总可直接 SUM；`order_cnt` 不可跨行相加，为订单去重计数。本需求已交付，并沉淀为固定报表。
