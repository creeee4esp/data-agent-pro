# 变更公告：调度时间调整（dws_trade_prov_refund_1d）

## 变更说明

`dws_trade_prov_refund_1d` 调整了调度开始时间，由数据平台组发布，2025-11-02 生效。

从调度安排看，该表作业开始时间由原 02:30 提前至 02:00，整体提前 30 分钟启动，产出时间相应前移。这样做的考量是让省份日度退款数据更早就绪，为下游留出更充裕的处理窗口。

对使用方的影响在于依赖链路的时点：依赖 `dws_trade_prov_refund_1d` 的下游作业与报表，可以更早拿到数据。建议核对自身依赖设置，确保在本表产出完成后再启动下游任务；若有定时任务按原 02:30 之后的时点读取本表，可据此适当前移。
