# 变更公告：新表上线（ads_trade_gmv_daily）

## 变更说明

`ads_trade_gmv_daily`（ADS-每日GMV报表）正式上线，现将有关事项通告如下。

### 一、变更内容

新增报表 `ads_trade_gmv_daily`，提供每日 GMV 口径的应用层产出，其上游来源为 `dws_trade_user_order_1d`。

### 二、生效日期

本次变更自 `2025-02-20` 起生效。

### 三、影响范围及应对

本次为新增产出，不涉及既有表的结构与数据变动。凡有每日 GMV 报表需求者，可自生效日期起直接接入 `ads_trade_gmv_daily`，无需另行改造。
