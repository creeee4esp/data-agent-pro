# 取数需求单 REQ-2025-0149

## 需求

财务部于 2025-06-22 提出的需求，落在收货省份维度的下单数 `order_cnt` 上，按月汇总，报告期为单月 2025-06，不设筛选条件。从提单背景看，财务部希望借此观察当月各收货省份的订单分布，为区域核算提供一个粗颗粒的参考视角。

## 结论

`dws_trade_prov_order_1m` 恰好对应这一诉求，取数落在 `stat_date`、`receiver_province`、`order_cnt`、`item_qty`、`paid_amount` 这几个字段上，以 `stat_date` 限定 2025-06 后按收货省份铺开即可。这里需要分析方留意一个口径细节：`order_cnt` 属于去重下单数，跨行相加会重复计数，因此不能简单把各省相加当作全国总量；相对地，`item_qty` 与 `paid_amount` 是可加和指标，按省或整体求和都成立。本次已交付一次性取数结果。
