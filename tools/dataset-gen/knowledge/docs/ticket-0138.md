# 取数需求单 REQ-2025-0138

## 需求

会员中心现提出取数需求，拟获取 2025-02 至 2025-03 期间各收货省份按日的退款笔数 `refund_cnt`，不附加筛选条件，用于各省售后退款规模的观察。

## 结论

经评估，`dws_trade_prov_refund_1d` 系收货省份粒度的按日退款汇总表，可满足本次要求。所取字段为 `stat_date`、`receiver_province`、`refund_cnt`、`refund_amount`，时间范围依 `stat_date` 限定于 2025-02 至 2025-03。

经核验口径，退款笔数 `refund_cnt` 与退款金额 `refund_amount` 均可跨行相加，故按省份跨日汇总、或按日跨省汇总以得到整体退款规模，均属可行，不致产生重复计数。

本需求已按一次性取数交付会员中心。
