# 取数需求单 REQ-2025-0033

## 需求

财务部于 2025-02-05 提出取数需求 REQ-2025-0033，关注买家用户粒度已支付订单的明细金额 `paid_amount`（单位元），希望按周汇总，时间范围覆盖 2025-01 至 2025-02，不设筛选条件。分析意图是跨这两个月观察各买家的支付金额走势。

## 结论

`dws_trade_user_order_1w` 作为来源表支撑这次取数，由物流数据组承接。维度从 `stat_date`、`buyer_id` 展开，输出指标为 `paid_amount` 已支付订单的明细金额。使用上要交代清楚：`item_qty` 与 `paid_amount` 可以跨行相加，按买家或按周汇总时可直接 SUM；而 `order_cnt` 为订单去重计数，不具备可加性，跨周或跨买家直接相加会重复，整体口径需回源计算。本需求已交付一次性取数结果。
