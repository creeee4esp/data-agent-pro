# 取数需求单 REQ-2025-0057

## 需求

客服部于 2025-03-05 提出取数需求 REQ-2025-0057，关注一级品类粒度的购买件数 `item_qty`，希望按日汇总，时间范围覆盖 2025-01 至 2025-03，不设筛选条件。分析意图是跨这三个月追踪各一级品类的件数走势，识别走量品类与季节性波动。

## 结论

`dws_trade_cate1_order_1d` 作为来源表支撑这次取数，由数据平台组承接。维度从 `stat_date`、`category1_id`、`category1_name` 展开，输出指标为 `item_qty` 购买件数。使用上需交代清楚：`item_qty` 与 `paid_amount` 可以跨行相加，按一级品类或按日汇总时可直接 SUM；而 `order_cnt` 为订单去重计数，不具备可加性，跨日或跨品类相加会重复，整体口径需回源计算。本需求已交付一次性取数结果。
