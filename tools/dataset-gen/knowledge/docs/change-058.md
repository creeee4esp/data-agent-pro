# 变更公告：调度时间调整（dws_lgs_prov_ship_1m）

## 变更说明

`dws_lgs_prov_ship_1m` 的调度开始时间从 `02:30` 提前到 `02:00`，这里说明一下背后的考量。

### 调整原因

从近期运行看，该表上游的发货明细在凌晨已较早就绪，而原先 `02:30` 的开始时间让省份月度发货汇总产出偏晚。将开始时间提前到 `02:00`，能让产出更早完成，也给依赖它的物流看板和下游汇总留出更充裕的缓冲。

### 生效、影响与动作

调整自 `2025-04-30` 起生效。汇总口径和数据内容均不变，仅出数时间前移半小时。下游任务无需改写，对出数节奏敏感的同学可据此微调自己的调度衔接。
