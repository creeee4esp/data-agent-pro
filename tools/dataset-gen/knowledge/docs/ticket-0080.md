# 取数需求单 REQ-2025-0080

## 需求

客服部需 2025-02 至 2025-03、按商品 SKU 粒度的周度总停留秒数 `stay_seconds`，无筛选，用于定位停留异常的商品。

## 结论

`dws_traffic_sku_visit_1w` 覆盖该需求，为商品 SKU 粒度的按周访问汇总表。

- 取数字段：`stat_date`、`sku_id`、`pv`、`uv`、`stay_seconds`
- 时间范围：`stat_date` 限定 2025-02 至 2025-03
- 可加：`stay_seconds`、`pv` 可跨行相加，跨周或多 SKU 汇总均成立
- 注意：`uv` 不可相加，同一访客跨周会重复计数，需去重须回访问明细
- 交付：已交付一次性取数结果
