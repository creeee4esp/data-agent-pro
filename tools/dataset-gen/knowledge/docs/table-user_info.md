# 表说明：user_info（用户基础信息表）

## 概述

`user_info` 为 CORE 层的用户基础信息表，记录每名用户的主数据，当前共 2,000 行。该表以用户为粒度，一行描述一名用户，是用户画像、会员结构与常住地域分析的核心维度来源。其数据经由业务系统同步而来，并被交易与地址等链路关联引用。

## 字段

- `user_id`（bigint）：用户 ID，作为用户的唯一标识，关联时以该字段为准。
- `user_name`（varchar(50)）：用户姓名，属个人信息，统计分析通常不直接使用。
- `gender`（char(1)）：性别，取值为 M-男、F-女、U-未知，按性别统计时须考虑未知值。
- `birth_year`（smallint）：出生年份，为年份值，计算年龄时须以当前年份相减。
- `province`（varchar(20)）：常住省份，如 浙江省、上海市，按常住地做地域分析时以该字段汇总。
- `city`（varchar(20)）：常住城市，可用于更细的城市级分析。
- `member_level`（tinyint）：会员等级，取值为 1-普通、2-白银、3-黄金、4-铂金、5-钻石，按会员层级统计时应使用对应枚举值。
- `register_time`（datetime）：注册时间，按注册日期做新增用户统计时以该字段为准。

## 上下游

`user_info` 的数据来自业务系统（在线数据库），同步后进入数据平台。其下游为 ODS 层的 `ods_user_info_di`，由后者承接并向上层加工。表内存在关联关系：`trade_order.buyer_id` 与 `user_address.user_id` 均指向 `user_info.user_id`，据此可将订单与地址关联至用户。

## 使用注意

`user_info` 适合用于用户画像、会员等级结构及常住地域分布等分析，不适合承载交易或访问行为，相关指标应取对应链路的表。需注意常住地 `province`、`city` 描述的是用户归属地，与订单收货省份并非同一概念，做地域分析时须明确所用口径。库内存在若干同家族噪声表：备份表 `user_info_bak`、带日期备份 `user_info_bak_20250708`、`user_info_bak_20251215`、旧版本 `user_info_v1` 以及测试表 `test_user_info`。上述表分别为历史快照、早期结构或调试用途，其口径与时效不受保证，不得用于正式统计。正式取数一律以 `user_info` 为准。
