# 取数需求单 REQ-2025-0044

## 需求

管理层于 2025-02-19 提出取数需求 REQ-2025-0044，关注一级品类粒度的购买件数 `item_qty`，希望按月汇总，时间范围覆盖 2025-01 至 2025-02，不设筛选条件。分析意图是跨这两个月横向比较各一级品类的件数贡献，判断哪些品类在走量。

## 结论

`dws_trade_cate1_order_1m` 作为来源表支撑这次取数，由物流数据组承接。维度从 `stat_date`、`category1_id`、`category1_name` 展开，输出指标为 `item_qty` 购买件数。使用上需交代清楚：`item_qty` 与 `paid_amount` 可以跨行相加，按一级品类或按月汇总时可直接 SUM；而 `order_cnt` 为订单去重计数，不具备可加性，跨行相加会重复，整体口径需回源计算。本需求已交付，附 SQL 供需求方自助复用。
