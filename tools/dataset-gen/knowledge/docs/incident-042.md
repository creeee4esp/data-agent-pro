# 数据事故报告：2025-11-17 dws_trade_prov_order_1d 数据重复

## 现象

`dws_trade_prov_order_1d`（DWS-收货省份粒度下单汇总（日））在 2025-11-17 被发现数据重复。当天核对的时候注意到收货省份粒度的日度下单汇总里有重复记录，同一个省份的下单被算了两遍，数值偏大。这个问题从发现到处理完持续了 2 小时。

## 原因与影响范围

`dws_trade_prov_order_1d` 这次重复的原因是任务重跑前未清理当天分区，重跑的数据直接叠到了原分区上，结果就重复了。影响面不大，没有下游表被牵连。

处理上我们补齐维表后重跑了一遍，把重复的数据清掉重新算。现在数据已经补好了，结果恢复正常。这次由物流数据组跟进。
