# 取数需求单 REQ-2025-0217

## 需求

财务部在 2025-09-11 提出取数需求，希望拿到 2025-07 的支付金额（`pay_amt`），按买家用户粒度的日度支付汇总口径呈现，不附加任何筛选。本单编号 REQ-2025-0217，由交易数据组处理。财务部的用意是以单个买家、按天的支付明细作为财务核对的基础数据。

## 结论

`dws_trade_user_pay_1d` 即 DWS-买家用户粒度支付汇总（日）正好契合这一需求，它以 `buyer_id` 加 `stat_date` 为粒度，输出 `pay_cnt` 与 `pay_amt`。本次取用 `stat_date`、`buyer_id`、`pay_cnt`、`pay_amt` 四个字段，报告期 `stat_date` 限定在 2025-07。

从加和角度看这张表很省心：`pay_cnt` 和 `pay_amt` 都可以跨行相加，无论是把多个买家汇总成全站支付金额，还是把一个买家多天的 `pay_amt` 累加成月度支付额，结果都是准确的。

考虑到财务对该口径有持续使用的诉求，本次已交付，并沉淀为固定报表供其定期取用。
