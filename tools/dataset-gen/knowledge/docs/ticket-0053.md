# 取数需求单 REQ-2025-0053

## 需求

商品部在 2025-03-03 提了需求 REQ-2025-0053，想分析一下广告投放效果，看看投放带来的回报。

## 结论

REQ-2025-0053 没法满足，由用户数据组评估后给的结论。原因很直接：仓库里压根没有广告投放数据，投放花费、曝光、点击这些都没进来，没有投放口径的字段，就没法算投放 ROI，也没法把成交归因到具体投放。替代的做法是从现有数据侧面看渠道贡献：用 `dws_trade_channel_pay_1d` 按支付渠道看支付笔数和支付金额的结构，用 `dws_traffic_vchannel_visit_1d` 按访问渠道看浏览量和访客数的来源分布，大致判断哪些渠道带来的成交和流量更多。要说清楚，这些是渠道层面的表现，不等于投放效果本身。等投放数据接入后再补。
