# 取数需求单 REQ-2025-0003

## 需求

运营部在 2025-01-03 提了个需求 REQ-2025-0003，想要访问用户粒度的浏览量 `pv`，按月统计，时间范围就 2025-01 这一个月，没有额外的筛选条件。他们主要是想看当月各访客的浏览情况，做运营侧的日常盘点。

## 结论

`dws_traffic_visitor_visit_1m` 这张表就能满足，由用户数据组接的这单。按月取 2025-01 的数据，维度用 `stat_date`、`visitor_id`，指标给到 `pv` 浏览量。这里要特别说一句：`pv` 和 `stay_seconds` 是可以跨行相加的，按访客汇总直接 SUM 就行；但 `uv` 不能跨行相加，它是去重访客数，把不同行的 `uv` 加起来会重复计数，要整体 `uv` 得回源去重。这次已经交付，并沉淀成固定报表了，以后每月自动出。
