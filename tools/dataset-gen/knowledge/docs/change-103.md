# 变更公告：提醒：备份 / 副本表列名与正表不一致（trade_order_202412）

## 变更说明

`trade_order_202412` 作为正表的月度备份副本，这次要提醒的是它和正表之间的一处列名差异，2025-08-27 起按此说明执行，由用户数据组发布。

从排查结果看，问题出在命名上：正表中的列叫 `pay_time`，而到了副本 `trade_order_202412` 里，同一含义的列被命名为 `pay_tm`。两者记录的都是支付时间，语义完全一致，差别仅在字段名。这意味着把正表的 SQL 原样搬到副本上执行，会因找不到 `pay_time` 列而报错。

影响范围集中在直接引用该备份副本的脚本与临时分析。建议使用方在查询 `trade_order_202412` 时，将 `pay_time` 改写为 `pay_tm`；若对取数时间口径有疑问，优先回正表核对，以免因命名差异误判数据缺失。
