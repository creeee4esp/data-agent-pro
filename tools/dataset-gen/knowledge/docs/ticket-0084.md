# 取数需求单 REQ-2025-0084

## 需求

财务部想要 2025-02 单月、按买家用户粒度看每天的退款金额 `refund_amount`（元），不加筛选，用来核对当月退款的资金流出。

## 结论

`dws_trade_user_refund_1d` 是买家用户粒度的按日退款汇总表，拿来正合适。字段取 `stat_date`、`buyer_id`、`refund_cnt`、`refund_amount`，按 `stat_date` 卡在 2025-02 这一个月就行。

口径上可以放心：退款金额 `refund_amount` 和退款笔数 `refund_cnt` 都是可以跨行相加的，所以把某个买家整月的退款金额加总，或者把全体买家当月汇成一个数，都没问题，财务对账时不会重复计算。

这次已经交付，并沉淀成了固定报表，财务部每月可以直接看。
