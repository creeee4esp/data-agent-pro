# 取数需求单 REQ-2025-0116

## 需求

物流部需 2025-04 至 2025-05、各一级品类按日的访客数 `uv`，无筛选，用于品类到访规模的跟踪。

- 时间范围：2025-04 至 2025-05
- 维度：一级品类
- 核心指标：访客数 `uv`

## 结论

`dws_traffic_cate1_visit_1d` 对口，为一级品类粒度的按日访问汇总表。

- 取数字段：`stat_date`、`category1_id`、`category1_name`、`pv`、`uv`、`stay_seconds`
- 时间范围：`stat_date` 限定 2025-04 至 2025-05
- 关键口径：`uv` 不可跨行相加，同一访客跨日或跨品类会重复计数，去重须回明细
- 可加：`pv`、`stay_seconds` 可跨行相加
- 交付：已交付，并沉淀为固定报表
