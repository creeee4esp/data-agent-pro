# 取数需求单 REQ-2025-0081

## 需求

管理层现提出取数需求，拟获取 2025-01 至 2025-03 期间各买家用户按日的支付笔数 `pay_cnt`，不附加筛选条件，用于观察用户支付行为的季度分布。

## 结论

经评估，`dws_trade_user_pay_1d` 系买家用户粒度的按日支付汇总表，可满足本次要求。所取字段为 `stat_date`、`buyer_id`、`pay_cnt`、`pay_amt`，时间范围依 `stat_date` 限定于 2025-01 至 2025-03。

经核验口径，支付笔数 `pay_cnt` 与支付金额 `pay_amt` 均可跨行相加，故按用户跨日汇总、或按日跨用户汇总以得到整体支付规模，均属可行，不致产生重复计数。

本需求已按一次性取数交付管理层。
