# 取数需求单 REQ-2025-0064

## 需求

物流部于 2025-03-15 提出取数需求 REQ-2025-0064，关注一级品类粒度已支付订单的明细金额 `paid_amount`（单位元），希望按日汇总，时间范围 2025-03，不设筛选条件。分析意图是看当月各一级品类的成交金额分布与日度节奏。

## 结论
