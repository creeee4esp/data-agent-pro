# 数据事故报告：2025-03-31 dws_trade_channel_pay_1d 产出延迟

## 现象

`dws_trade_channel_pay_1d`（DWS-支付渠道粒度支付汇总（日））于 2025-03-31 经监控发现产出延迟。核查确认，该表支付渠道粒度的日度支付汇总未在例行窗口内完成刷新，下游在取数时读到的仍为上一分区数据，属产出延迟类事故。事故自发现起持续 1 小时。

## 原因与影响范围

`dws_trade_channel_pay_1d` 本次延迟的根本原因为上游 ODS 同步超时，致使本表计算入口被阻塞、调度被动顺延。经排查，本次事故未波及任何下游表，影响范围限于该表自身。

处理方面，用户数据组在修复 SQL 后回刷了近 7 天的数据，确保延迟期间相关分区一并得到纠正。截至报告出具，相关数据已完成补数，表恢复正常产出。
