# 数据事故报告：2025-01-21 dws_trade_prov_order_1w 关键字段为空

## 现象

`dws_trade_prov_order_1w`（DWS-收货省份粒度下单汇总（周））在 2025-01-21 被发现关键字段为空。从现象上追溯，收货省份粒度的周度下单汇总中，本应承载维度信息的关键字段出现空值，使得按省份切分的口径无法正常落地。问题从发现到处置共持续 3 小时。

## 原因与影响范围

处理层面，商品数据组采取了重跑当天任务并补数的方式，使空值字段重新填充正确。目前数据已补齐，表恢复可用状态。
