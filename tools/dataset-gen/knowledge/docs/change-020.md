# 变更公告：提醒：备份 / 副本表列名与正表不一致（trade_order_20251109）

## 变更说明

`trade_order_20251109` 这张带日期的备份表，列名与正表对不上，这里提醒大家在引用时留意。

### 问题细节

正表里的支付金额列叫 `pay_amount`，而这张备份里同一列被命名为 `pay_amt`。含义完全相同，只是字段名做了缩写。于是，拿写正表的 SQL 直接查备份会因找不到 `pay_amount` 报错，凭备份习惯在正表写 `pay_amt` 也同样查不到。

### 影响与动作

影响面是所有读取 `trade_order_20251109` 的查询。自 `2025-02-14` 起，请按本提醒对齐：查该备份时把金额列写成 `pay_amt`，正式分析仍以正表的 `pay_amount` 为准，不建议把备份当长期数据源。
