# 取数需求单 REQ-2025-0060

## 需求

客服部在 2025-03-07 提了需求 REQ-2025-0060，想要承运商粒度的平均发货时长 `avg_ship_hours`（单位小时），按周汇总，时间范围 2025-01 至 2025-02，没有筛选条件。他们想比较各承运商这两个月的时效。

## 结论

`dws_lgs_carrier_ship_1w` 这张表能满足，由流量数据组接的单。按周取 2025-01 至 2025-02 数据，维度用 `stat_date`、`carrier`，指标给 `avg_ship_hours` 平均发货时长。这里得重点提醒：`avg_ship_hours` 不能跨行相加，要跨承运商或跨周算整体平均时长，得用 `ship_cnt` 作权重加权，直接把各行该列加起来没有意义；同表的 `ship_cnt`、`signed_cnt` 可以跨行相加。这次已交付一次性取数结果。
