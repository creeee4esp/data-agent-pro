# 表说明：dws_trade_prov_order_1m（DWS-收货省份粒度下单汇总（月））

## 概述

`dws_trade_prov_order_1m` 按统计月和收货省份汇总下单，当前 192 行。先提醒一句，`stat_date` 存的是月初日期，代表整月，不是具体某天，刚上手容易误会。数据来自交易明细 `dwd_trade_order_detail_di`，下单数去重、件数和已支付金额求和，口径和日表周表一致。

## 字段

- `stat_date`：统计月，取月初日期，按月筛选要用月初日期去匹配。
- `receiver_province`：收货省份，和 `stat_date` 一起决定一行，同月同省只有一条。
- `order_cnt`：下单数，当月去重后的订单计数，可以跨月相加。
- `item_qty`：购买件数，含未支付订单，看销量时记得口径偏大。
- `paid_amount`：已支付订单的明细金额（元），只算已支付那部分，别当成当月下单总额。

## 上下游

来源是交易明细表 `dwd_trade_order_detail_di`，加工时按月初日期和 `receiver_province` 分组聚合写入本表，目前没有下游表。需要更高层汇总时一般直接在本表上再聚合。

## 使用注意

想看各省份的月度走势、月度同比环比、或者省份月度排名，用这张表很方便，一月一省一行。要日或周粒度就别用它，请改用对应的日表、周表。同家族里有一张带日期备份 `dws_trade_prov_order_1m_bak_20250820`，它是某次操作前留下的历史快照，数据未必是最新的，做统计时认准本表就好，不要误取到这张备份上。
