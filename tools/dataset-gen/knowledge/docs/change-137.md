# 变更公告：新表上线（dws_lgs_carrier_ship_1d）

## 变更说明

`dws_lgs_carrier_ship_1d` 正式上线，表注释为“DWS-承运商粒度发货汇总（日）”，由流量数据组发布，2025-12-04 生效。

从数据链路看，该表上游为 `dwd_lgs_shipment_di`，在发货明细基础上按承运商、日粒度做了汇总。这样处理后，分析各承运商的日度发货表现时可直接复用这张汇总表，无需每次从明细层重新聚合，既省算力又统一了口径。

对使用方而言，自生效日起即可接入 `dws_lgs_carrier_ship_1d` 取数，需留意其粒度为承运商 × 日。需要提醒的是，上游 `dwd_lgs_shipment_di` 若产出异常或延迟，本表也会相应受影响，依赖本表的作业请关注上游状态。
