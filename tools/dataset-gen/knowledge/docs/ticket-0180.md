# 取数需求单 REQ-2025-0180

## 需求

商品部于 2025-08-04 提出的需求，围绕收货省份粒度的平均发货时长 `avg_ship_hours`（单位：小时）展开，按周汇总，报告期区间为 2025-03 至 2025-04，不设筛选条件。从背景看，商品部想了解这段时间各省的发货时效差异，为商品页上的时效承诺提供参考。

## 结论

`dws_lgs_prov_ship_1w` 对应这一诉求，取数落在 `stat_date`、`receiver_province`、`ship_cnt`、`signed_cnt`、`avg_ship_hours` 这几个字段上，以 `stat_date` 限定 2025-03 至 2025-04 后按收货省份与周铺开即可。分析时要特别注意：`avg_ship_hours` 是平均发货时长，不能跨行直接相加或求平均，若要得到跨周或跨省的整体时效，应按发货单数加权重算；相对地，`ship_cnt` 与 `signed_cnt` 是可加和指标，汇总无碍。本次已交付一次性取数结果。
