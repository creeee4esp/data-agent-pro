# 指标说明：签收率（签收率）

## 计算公式

签收率为派生指标，由已签收单数与发货单数相除得到。

- 口径：signed_cnt / ship_cnt。
- 可加和：否。比率不能跨行、跨天相加或取平均。
- 更长周期：把 signed_cnt 和 ship_cnt 各自汇总后再相除。

## 取哪张表

签收率需由分子分母现算，不单独存字段。

- 参考表：`dws_lgs_carrier_ship_1d`，从中取 signed_cnt 与 ship_cnt 相除。
- 要求：分子分母取自同一时间范围、同一维度。

## 来源与历史变化

签收率由已签收单数与发货单数派生而来，不独立存储。

- 历史变更：自上线以来未调整计算规则。
- 口径一致，可直接用于跨期趋势比较。
