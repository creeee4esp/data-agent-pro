# 取数需求单 REQ-2025-0055

## 需求

市场部于 2025-03-04 正式提出需求 REQ-2025-0055，请求分析广告投放效果，评估各项投放的产出与转化表现。

## 结论

REQ-2025-0055 经评估无法满足，由商品数据组给出结论。核心原因在于，现有数据仓库未纳入广告投放数据，缺少投放花费、曝光量、点击量等关键记录，故无法构建投放口径下的效果指标，亦无法完成投放与成交之间的归因分析。作为可替代方案，建议从现有成交与流量数据切入：依托 `dws_trade_channel_pay_1d` 按支付渠道考察支付笔数与支付金额的结构，依托 `dws_traffic_vchannel_visit_1d` 按访问渠道考察浏览量与访客数的来源分布，以间接反映各渠道的贡献与趋势。需特别说明，上述分析为渠道层面的表现度量，不能等同于广告投放效果。待投放数据接入后再行补充。
