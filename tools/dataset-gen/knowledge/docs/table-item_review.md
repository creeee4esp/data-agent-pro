# 表说明：item_review（商品评价表）

## 概述

`item_review` 为 CORE 层的商品评价表，记录用户对已购商品的评价明细，当前共 16,845 行。该表以单条评价为粒度，一行对应一次评价，可用于评分分布、带图率、品类或商品口碑等分析。由于评价行为发生在收货之后，表内时间字段与交易、物流链路存在先后约束，使用时应结合业务时序理解数据。

## 字段

- `review_id`（bigint）：评价 ID，作为单条评价的唯一标识。
- `order_item_id`（bigint）：订单明细 ID，用于定位被评价的具体订单明细，关联时以该字段为准。
- `sku_id`（bigint）：商品 SKU ID，标识被评价的商品，适用于按商品聚合评价。
- `user_id`（bigint）：评价用户 ID，标识发表评价的用户。
- `rating`（tinyint）：评分，取值为 1～5 星，统计好评率等指标时须明确所用的评分阈值。
- `has_image`（tinyint）：是否带图，1 表示是、0 表示否，计算带图率时应以该枚举值过滤。
- `review_time`（datetime）：评价时间，晚于签收时间，按时间窗口统计时须注意其滞后性。

## 上下游

`item_review` 的数据来自业务系统（在线数据库），同步后进入数据平台，其下游为 ODS 层的 `ods_item_review_di`，由后者承接并向上层加工。表内存在关联关系：`item_review.order_item_id` 指向 `trade_order_item.id`，可据此回溯评价对应的订单明细。

## 使用注意

`item_review` 适合用于评分分布、带图率、商品或品类口碑等评价维度的统计分析，不适合用于交易金额或物流时效类指标，后者应取对应的交易、物流数据。库内存在大量同家族噪声表：备份表 `item_review_bak`、按日拆分的日分表（范围为 `item_review_20250101 ～ item_review_20251231`，如 `item_review_20250101`）以及按月拆分的月分表（范围为 `item_review_202301 ～ item_review_202512`，如 `item_review_202301`）。日分表与月分表为历史按期拆分的存档，备份表为历史快照，其口径与完整性均不受保证，不得用于正式统计。正式取数一律以 `item_review` 为准。
