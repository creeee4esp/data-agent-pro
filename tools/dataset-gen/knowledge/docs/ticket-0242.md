# 取数需求单 REQ-2025-0242

## 需求

会员中心 2025-10-16 来问，能不能分析商家或店铺，想看单个店铺的经营数据。单号 REQ-2025-0242，流量数据组接的。

## 结论

这条需求目前没法满足。我们的数据仓库是按商品、品类、品牌、用户、省份、渠道这些维度汇总的，没有建到商家或店铺这一层，所以拿不到单店铺粒度的指标，硬拆也只是把别的维度套个名字，数据不准。

可替代的思路是换个能对上的维度来看：如果关注的是某品牌的表现，可以用品牌粒度的下单、评价汇总；如果关注的是某类商品，可以走一级或二级品类粒度；想看区域差异就用收货省份粒度。先确认你真正想回答的业务问题，我们再挑一个现有维度帮你出数。等后续数仓补上店铺维度，再按店铺口径单独支持。
