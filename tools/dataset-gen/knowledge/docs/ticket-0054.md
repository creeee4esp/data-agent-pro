# 取数需求单 REQ-2025-0054

## 需求

市场部于 2025-03-04 提出取数需求 REQ-2025-0054，关注承运商粒度的已签收单数 `signed_cnt`，希望按周汇总，时间范围 2025-01，不设筛选条件。分析意图是横向比较各承运商当月的签收完成情况，为承运合作评估提供输入。

## 结论

`dws_lgs_carrier_ship_1w` 作为来源表支撑这次取数，由物流数据组承接。维度从 `stat_date`、`carrier` 展开，输出指标为 `signed_cnt` 已签收单数。使用上需交代清楚：`ship_cnt` 与 `signed_cnt` 可以跨行相加，按承运商或按周汇总时可直接 SUM；而 `avg_ship_hours` 作为平均发货时长不具备可加性，若要整体平均值须按单量加权，不能对该列直接相加。本需求已交付，并沉淀为固定报表。
