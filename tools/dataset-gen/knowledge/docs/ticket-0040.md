# 取数需求单 REQ-2025-0040

## 需求

物流部于 2025-02-17 提出取数需求 REQ-2025-0040，要用户粒度的支付订单数 `paid_order_cnt`，口径按日，时间范围 2025-01 至 2025-02，无筛选条件。诉求是看这两个月各用户的支付订单情况。

## 结论

`dws_trade_user_order_1d` 为本次用表，由用户数据组处理交付。维度取 `stat_date`、`buyer_id`，指标输出 `paid_order_cnt` 支付订单数。可加性提示：`paid_amount` 可跨行相加；`order_cnt`、`paid_order_cnt` 不可跨行相加，二者为用户级订单去重计数，跨日或跨用户相加会重复，整体口径须回源计算。本需求已交付，附 SQL 供需求方自助复用。
