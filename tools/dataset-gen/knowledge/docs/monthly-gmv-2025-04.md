# 交易 GMV 月报：2025-04

## 概览

2025-04 交易 GMV 回落至 3,255,589.10 元，环比 -7.8%，结束了上月的增长势头。本月支付订单数 1,328，支付买家数 645，客单价（GMV/支付订单数）为 2,451.50 元；单日最高落在 2025-04-26，当天 GMV 203,140.10 元。

## 结论
