# 取数需求单 REQ-2025-0009

## 需求

市场部于 2025-01-12 正式提出取数需求 REQ-2025-0009。需求方请求提供会员等级粒度的下单数 `order_cnt`，统计口径为按周汇总，时间范围为 2025-01，不设任何筛选条件。此项数据拟用于会员分层的下单情况分析。

## 结论

`dws_trade_level_order_1w` 经评估确定为本次取数的来源表，由交易数据组负责处理与交付。取数维度采用 `stat_date` 与 `member_level`，输出指标为 `order_cnt` 下单数。特此说明可加性要求：`item_qty` 与 `paid_amount` 可跨行相加，按会员等级或按周汇总时可直接求和；`order_cnt` 不可跨行相加，该指标为订单去重计数，跨行相加将导致重复，如需整体口径应回源重新统计。本需求已交付一次性取数结果。
