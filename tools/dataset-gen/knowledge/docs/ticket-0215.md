# 取数需求单 REQ-2025-0215

## 需求

客服部于 2025-09-09 正式提出取数申请，请求提供 2025-06 的平均评分（`avg_rating`），统计口径为品牌粒度评价月度汇总，不设附加筛选条件。本单编号 REQ-2025-0215，交由商品数据组承办。

## 结论

`dws_item_brand_review_1m` 即 DWS-品牌粒度评价汇总（月）为本次取数之依据表。所取字段为 `stat_date`、`brand_name`、`review_cnt`、`good_cnt`、`avg_rating`，报告期 `stat_date` 限定为 2025-06。

须特别说明：`avg_rating` 系平均值性质，不得跨行相加，若需汇总多品牌的总体平均评分，应以 `review_cnt` 为权重加权计算，不可将各品牌 `avg_rating` 简单求和或求算术平均。`review_cnt` 与 `good_cnt` 则可跨行相加，用于统计评价总数与好评总数。
