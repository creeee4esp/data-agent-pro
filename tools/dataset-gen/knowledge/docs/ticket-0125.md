# 取数需求单 REQ-2025-0125

## 需求

物流部想要 2025-01 至 2025-02、按支付渠道看每周的支付金额 `pay_amt`（元），不加筛选，用来对比不同渠道的资金回流规模。

## 结论

`dws_trade_channel_pay_1w` 是支付渠道粒度的按周支付汇总表，拿它来做正合适。字段取 `stat_date`、`pay_channel`、`pay_cnt`、`pay_amt`，按 `stat_date` 卡在 2025-01 到 2025-02 的周区间。

口径上可以放心加：支付金额 `pay_amt` 和支付笔数 `pay_cnt` 都是可以跨行相加的，把某个渠道多周累加、或者把各渠道汇成大盘再看占比，都没问题，不会重复计算。物流部可以据此排出两个月里各支付渠道的金额和笔数分布。

这次已经按一次性取数交付物流部了。
