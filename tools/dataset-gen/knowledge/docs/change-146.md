# 变更公告：提醒：备份 / 副本表列名与正表不一致（trade_order_20250128）

## 变更说明

`trade_order_20250128` 这张备份副本的列名和正表对不上，提前跟大家说一声，2025-12-25 起按此提醒执行，交易数据组发布。

情况是这样：正表里叫 `pay_amount` 的列，到了副本 `trade_order_20250128` 里被写成了 `pay_amt`。两列存的都是支付金额，意思一样，就是名字不同。所以直接把正表的 SQL 搬过来跑，会因为找不到 `pay_amount` 而报错。

影响的主要是直接查这张副本的脚本和临时分析。大家用 `trade_order_20250128` 时记得把 `pay_amount` 换成 `pay_amt`；要是对金额口径有疑问，建议回正表核对，别因为字段名不一样就误判数据少了。
