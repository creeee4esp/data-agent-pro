# 取数需求单 REQ-2025-0099

## 需求

市场部想查询商品库存，看看各单品还有多少可售量，用来配合促销排期判断哪些货能冲量、哪些要控节奏。

## 结论

这个需求当前无法满足。原因是数据仓库里没有库存相关的表，现有的 DWS 汇总表覆盖的是交易、支付、退款、访问、评价和发货履约等主题，并不包含实时库存或可售量字段，所以查不到库存数据。

可替代的分析可以从销售侧入手：用交易类汇总看单品近一段时间的下单与支付走势，判断动销快慢，间接推断补货优先级；也可以结合发货履约数据看出库节奏。若确实需要库存口径，这属于要接入库存系统、新建数据模型的需求，需另行立项评估，不在本次取数范围内。本单据先按不可满足结案。
