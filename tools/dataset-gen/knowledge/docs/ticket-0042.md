# 取数需求单 REQ-2025-0042

## 需求

物流部在 2025-02-18 提了需求 REQ-2025-0042，想要访问用户粒度的总停留秒数 `stay_seconds`，按日汇总，时间范围 2025-01 至 2025-02，没有筛选条件。他们想看这两个月各访客的停留时长变化。

## 结论

`dws_traffic_visitor_visit_1d` 这张表能满足，由流量数据组接的单。按日取 2025-01 至 2025-02 数据，维度用 `stat_date`、`visitor_id`，指标给 `stay_seconds` 总停留秒数。可加性提醒下：`pv` 和 `stay_seconds` 能跨行相加，按访客或按日汇总直接 SUM 就行；`uv` 不能跨行相加，是去重访客数，不同行加起来会重复，整体 `uv` 要回源去重。这次已交付，并沉淀为固定报表。
