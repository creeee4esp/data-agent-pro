# 支付渠道月报：2025-01

## 概览

支付渠道月报 2025-01 的支付金额合计为 3,036,621.56 元。本月一共四个支付渠道有流水，其中 alipay 金额最高，占比 35.01%；wechat 和 card 紧随其后，占比分别为 27.54% 和 25.42%；unionpay 占比 12.03%，排在最后。整体看三方支付（alipay + wechat）合起来已经超过六成。
