# 数据事故报告：2025-05-11 dws_trade_prov_refund_1m 产出延迟

## 现象

`dws_trade_prov_refund_1m`（DWS-收货省份粒度退款汇总（月））在 2025-05-11 被发现产出延迟。当天到了该出数的点，收货省份粒度的月度退款汇总迟迟没刷出来，下游同学取数的时候读到的还是旧的分区。前后拖了 4 小时才恢复。

## 原因与影响范围

`dws_trade_prov_refund_1m` 这次延迟的原因是集群资源不足排队，任务排在队里一直等资源，开始得晚自然就出得晚。影响面不大，没有下游表被牵连。

处理上我们修复 SQL 后回刷了近 7 天的数据，把延迟那几天可能有问题的分区一起刷了。现在数据已经补好了，产出也回到正常节奏。这次由流量数据组跟进。
