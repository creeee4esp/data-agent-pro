# 取数需求单 REQ-2025-0220

## 需求

市场部在 2025-09-16 提出取数，关注 2025-03 至 2025-04 的下单数（`order_cnt`），希望按一级品类粒度、日度口径观察各品类的下单走势，不设筛选条件。本单编号 REQ-2025-0220，处理人数据平台组。市场部的分析意图是对比春季两个月间各品类的下单节奏。

## 结论

`dws_trade_cate1_order_1d` 即 DWS-一级品类粒度下单汇总（日）支撑了这次分析，取 `stat_date`、`category1_id`、`category1_name`、`order_cnt`、`item_qty`、`paid_amount`，报告期 `stat_date` 覆盖 2025-03 至 2025-04 的每一天。

分析时有个口径要特别留心：`order_cnt` 不可跨行相加，想得到某品类两个月的下单总量时不能把日度 `order_cnt` 逐日累加，那样会因同一订单跨日重复而虚高，建议按日观察趋势，或改用去重口径。`item_qty`、`paid_amount` 则可跨行相加，适合做月度小计。
