# 取数需求单 REQ-2025-0058

## 需求

管理层在 2025-03-05 提了需求 REQ-2025-0058，想要访问用户粒度的访客数 `uv`，按日汇总，时间范围 2025-01 至 2025-03，没有筛选条件。他们想看这三个月整体访客规模的走势。

## 结论

`dws_traffic_visitor_visit_1d` 这张表能满足，由流量数据组接的单。按日取 2025-01 至 2025-03 数据，维度用 `stat_date`、`visitor_id`，指标给 `uv` 访客数。可加性这里得重点说：`uv` 不能跨行相加，是去重访客数，把不同天或不同访客的 `uv` 加起来会重复计数，要整体 `uv` 必须回源去重；同表 `pv`、`stay_seconds` 可以跨行相加。这次已交付，并沉淀为固定报表。
