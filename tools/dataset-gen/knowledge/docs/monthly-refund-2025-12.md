# 退款月报：2025-12

## 概览

退款月报 2025-12 的退款率（按下单月）为 5.51%，与上月退款率 5.45% 基本持平，微升 0.06 个百分点。本月支付订单数 1,687，退款订单数 93。退款水平连续两个月稳定在 5.5% 附近。

## 分维度

本月完成的退款按原因（按退款完成月）分布如下表。

| 退款原因 | 笔数 | 退款金额 |
| --- | --- | --- |
| quality | 28 笔 | 37,752.08 元 |
| late_delivery | 23 笔 | 42,820.65 元 |
| no_longer_needed | 22 笔 | 17,660.45 元 |
| wrong_item | 18 笔 | 19,839.42 元 |

就笔数而言，quality 以 28 笔居首；就金额而言，late_delivery 以 42,820.65 元最高，其笔数虽为 23 笔，单笔金额却相对偏高。

## 结论

现就 2025-12 情况提出以下意见：

- 退款率 5.51% 与上月基本持平，连续两月保持平稳，整体风险可控。
- late_delivery 金额居首、quality 笔数最多，二者为本月退款主要构成，建议重点跟踪。
- no_longer_needed 笔数虽居第三，退款金额却为各原因最低，对金额影响有限。
