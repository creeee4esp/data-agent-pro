# 取数需求单 REQ-2025-0210

## 需求

运营部于 2025-08-30 提出的需求，核心是想算利润和毛利。从沟通可以看出，运营部希望在成交数据之外，进一步衡量各活动或品类的盈利能力，用来判断投入产出是否划算，而不仅仅停留在成交金额这一层。

## 结论

利润与毛利目前无法满足，根本原因在于缺少关键口径——数据仓库里只有成交与支付侧的金额，并没有商品成本数据，没有成本就算不出利润，毛利率更无从谈起。与其给出一个无法支撑决策的数字，不如换个能落地的角度：可以用已支付订单的明细金额这类可加和的成交口径，配合退款金额来观察净收入的变化趋势，也可以按品类、品牌拆解成交结构，找出贡献最高的部分，间接评估经营效率。等后续接入成本数据后，再补齐利润相关的核算。本次结论为无法满足，已向运营部说明原因并给出可替代的分析方向。
