# 取数需求单 REQ-2025-0048

## 需求

管理层于 2025-02-23 提出取数需求 REQ-2025-0048，关注一级品类粒度的访客数 `uv`，希望按周汇总，时间范围覆盖 2025-01 至 2025-02，不设筛选条件。分析意图是跨这两个月观察各一级品类的访客规模变化。

## 结论

`dws_traffic_cate1_visit_1w` 作为来源表支撑这次取数，由交易数据组承接。维度从 `stat_date`、`category1_id`、`category1_name` 展开，输出指标为 `uv` 访客数。这里有个必须讲清的要点：`uv` 是去重访客数，不能跨行相加，把不同品类或不同周的 `uv` 相加会重复计数，若要整体 `uv` 必须回源去重；而同表的 `pv`、`stay_seconds` 可以跨行相加。本需求已交付一次性取数结果。
