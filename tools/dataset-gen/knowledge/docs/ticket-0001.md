# 取数需求单 REQ-2025-0001

## 需求

商品部于 2025-01-01 提出取数需求 REQ-2025-0001，要仓库粒度的发货单数 `ship_cnt`，口径为按日汇总，时间范围 2025-01，无额外筛选条件。业务方希望看到当月各仓库的发货表现，用于日常发货节奏的监控。

## 结论

`dws_lgs_warehouse_ship_1d` 为本次取数的落地表，由用户数据组处理交付。按日拉取 2025-01 各仓库数据，取 `stat_date`、`warehouse_id`、`warehouse_region` 作维度，输出 `ship_cnt` 发货单数。需要提醒：`ship_cnt` 与 `signed_cnt` 可跨行相加，按仓库或按日汇总均可直接 SUM；`avg_ship_hours` 为平均值，不能跨行相加，如需整体平均发货时长应回到明细重新加权，不可对该列直接求和。本需求已交付，并沉淀为固定报表，后续每日自动产出。
