# 变更公告：提醒：备份 / 副本表列名与正表不一致（item_review_202406）

## 变更说明

`item_review_202406` 这张月份备份表，用户列的名字和正表不一样，提醒大家取数时别用错。

### 具体情况

正表里用户列叫 `user_id`，这张备份里同一列写成了 `usr_id`。意思完全一样，就是名字做了缩写。所以直接拿写正表的 SQL 查备份会报错，凭备份习惯在正表写 `usr_id` 也查不到。

### 生效与影响

`2025-04-29` 起请按本提醒对齐。影响的是引用 `item_review_202406` 的查询：查这张备份时列名写 `usr_id`，正式分析还是以正表的 `user_id` 为准，别把它当长期数据源。
