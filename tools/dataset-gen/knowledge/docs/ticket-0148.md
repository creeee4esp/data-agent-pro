# 取数需求单 REQ-2025-0148

## 需求

管理层在 2025-06-22 提了个需求，想看 SKU 粒度的总停留秒数 `stay_seconds`，按日汇总，时间范围是 2025-02 到 2025-03，不加筛选。主要是想了解年初这两个月各 SKU 的用户停留情况，作为后续页面优化的参考。

## 结论

`dws_traffic_sku_visit_1d` 这张表可以满足，取数用到 `stat_date`、`sku_id`、`pv`、`uv`、`stay_seconds` 这几个字段，按 `stat_date` 卡 2025-02 至 2025-03 就行。有一点要注意：`pv` 和 `stay_seconds` 是可以跨行相加的，按 SKU 或按月汇总都没问题；但 `uv` 是去重访客数，不能跨行累加，想看一段时间的整体 `uv` 得回去重算。本次已交付，并附了 SQL 方便管理层那边自助复用。
