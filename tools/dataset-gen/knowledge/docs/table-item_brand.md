# 表说明：item_brand（商品品牌表）

## 概述

`item_brand` 为 CORE 层的商品品牌维表，记录公司在售商品所涉及的品牌基础信息，当前共 12 行。该表以品牌为粒度，一行描述一个品牌，可用于品牌画像、品牌维度的归类与关联分析。因数据量极小且更新不频繁，适合作为维度表被其它事实数据关联引用。

## 字段

- `brand_id`（int）：品牌 ID，作为品牌的唯一标识，关联时应以该字段为准。
- `brand_name`（varchar(50)）：品牌名称，与 `item_sku.brand_name` 对应，按名称关联商品时需注意两侧取值一致。
- `origin_country`（varchar(20)）：品牌所属国家或地区，适用于按来源地做品牌分布统计。
- `founded_year`（smallint）：品牌创立年份，为年份值，计算品牌成立年限时须以当前年份相减。
- `brand_level`（varchar(10)）：品牌等级，取值为 S、A、B 三档，筛选高等级品牌时应使用对应枚举值。

## 上下游

`item_brand` 的数据来自业务系统（在线数据库），经同步进入数据平台。其下游为 ODS 层的 `ods_item_brand_di`，由后者承接并向上层维度加工延伸，因此变更该表字段时需评估对下游的影响。

## 使用注意

`item_brand` 适合用于品牌名称、来源地、创立年份及等级等维度的查询与关联，不适合承载交易或访问类的量值统计，后者应取对应的事实表或汇总表。库内存在若干同家族的噪声表：备份表 `item_brand_bak`、带日期备份 `item_brand_bak_20250927`、旧版本 `item_brand_v2` 以及测试表 `test_item_brand`。上述表分别为历史快照、早期结构或调试用途，其内容的口径与时效均不受保证，不得用于正式统计。正式取数一律以 `item_brand` 为准。
