# 取数需求单 REQ-2025-0194

## 需求

财务部于 2025-08-19 提出的需求，围绕品牌粒度的评价数 `review_cnt` 展开，按周汇总，报告期为单月 2025-07，不设筛选条件。从背景看，财务部希望长期跟踪各品牌的评价规模变化，作为品牌经营质量的一个旁证口径，因此希望把这份数据固化下来。

## 结论

`dws_item_brand_review_1w` 对应这一诉求，取数落在 `stat_date`、`brand_name`、`review_cnt`、`good_cnt`、`avg_rating` 这几个字段上，以 `stat_date` 限定 2025-07 后按品牌与周铺开即可。分析时需区分指标口径：`review_cnt` 与 `good_cnt` 是可加和指标，跨周或跨品牌求和都成立；而 `avg_rating` 是平均评分，不能跨行直接相加，若要整体平均须按评价数加权重算。考虑到财务部的长期跟踪需求，本次已交付，并沉淀为固定报表。
