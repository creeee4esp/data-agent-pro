# 变更公告：补充字段注释（dwd_traffic_visit_di）

## 变更说明

`dwd_traffic_visit_di` 这次补充的是 `visit_date` 字段的注释，将其含义明确为“访问日期”，由用户数据组发布，2025-12-26 生效。

从影响面看，这是一次元数据层面的补充，字段类型和数据值都不变，历史数据也不回刷，取数结果不受影响。补充的意义在于让按日期过滤与分组时的字段含义更清晰：`visit_date` 记录的是访问发生的日期，使用方可据此准确理解时间维度。

使用方无需调整现有 SQL，建议生效后刷新元数据缓存，使最新注释正确展示；在做日粒度流量分析时，直接以 `visit_date` 作为访问日期维度引用即可。
