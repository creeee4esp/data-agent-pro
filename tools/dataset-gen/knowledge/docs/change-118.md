# 变更公告：新表上线（dws_trade_user_refund_1d）

## 变更说明

`dws_trade_user_refund_1d` 上线了，跟大家同步下情况，2025-10-06 生效，商品数据组发布。

这张表的表注释是“DWS-买家用户粒度退款汇总（日）”，上游取自 `dwd_trade_refund_di`，按买家用户加日粒度把退款数据汇好，方便做用户维度的日度退款分析，不用大家自己从明细层往上卷。

想用的同学从生效日起直接接 `dws_trade_user_refund_1d` 就行，注意它的粒度是买家用户 × 日。另外上游 `dwd_trade_refund_di` 要是当天跑得晚或出问题，这张表的产出也会跟着延迟，依赖它的作业记得留意一下依赖状态。
