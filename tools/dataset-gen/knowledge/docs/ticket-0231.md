# 取数需求单 REQ-2025-0231

## 需求

市场部在 2025-10-04 提出取数，关注 2025-05 至 2025-06 的发货单数（`ship_cnt`），希望按承运商粒度、月度口径对比各承运商的发货量，不设筛选条件。本单编号 REQ-2025-0231，处理人数据平台组。市场部意在评估两个月内各承运商的承运规模。

## 结论

`dws_lgs_carrier_ship_1m` 即 DWS-承运商粒度发货汇总（月）对应本次取数，取 `stat_date`、`carrier`、`ship_cnt`、`signed_cnt`、`avg_ship_hours`，报告期 `stat_date` 覆盖 2025-05 与 2025-06。

加和方面：`ship_cnt` 与 `signed_cnt` 可跨行相加，把各承运商、两个月的 `ship_cnt` 汇总得到总发货单量是准确的。需要提醒的是 `avg_ship_hours` 为平均值，不可跨行相加，若要比较整体发货时效，应以 `ship_cnt` 为权重加权，不能简单取算术平均。

考虑到承运商评估有持续需要，本次已交付，并沉淀为固定报表。
