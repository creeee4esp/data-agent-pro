# 变更公告：调度时间调整（dws_trade_prov_pay_1m）

## 变更说明

`dws_trade_prov_pay_1m` 的调度开始时间从 `03:30` 提前到 `03:00`，这里说明一下调整的考量。

### 调整原因

观察近段时间的运行情况，该表上游的支付明细在凌晨已较早就绪，原先 `03:30` 启动让月度省份支付汇总产出偏晚。把开始时间提前到 `03:00`，可以让产出更早完成，给依赖它的省份支付看板和下游汇总留出更多处理时间。

### 生效、影响与动作

调整自 `2025-04-03` 起生效。汇总口径和数据内容均不变，只是出数时间前移半小时。下游任务无需改写，但对出数节奏卡得紧的同学可以据此调整自己的调度衔接。
