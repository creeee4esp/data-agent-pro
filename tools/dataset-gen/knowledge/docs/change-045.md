# 变更公告：提醒：备份 / 副本表列名与正表不一致（pay_order_20250405）

## 变更说明

`pay_order_20250405` 这张带日期的备份表，支付时间列的命名和正表不一样，这里提醒大家取数时别搞混。

### 问题细节

正表里支付时间列叫 `pay_time`，备份里同一列被写成了 `pay_tm`。两者含义一致，只是备份做了缩写。结果就是：拿写正表的 SQL 去查备份，会因为没有 `pay_time` 而报错；凭备份习惯在正表上写 `pay_tm` 同样查不到。

### 影响与动作

影响面是所有读取 `pay_order_20250405` 的查询。自 `2025-04-02` 起，请按本提醒对齐：查备份时列名写成 `pay_tm`，正式的时间维度分析仍以正表的 `pay_time` 为准，尽量别把备份当长期数据源用。
