# 加工说明：ods_user_info_di

## 加工逻辑

`ods_user_info_di`（ODS-用户基础信息表）承接业务库 `user_info` 的原始数据，作为贴源层不实施清洗、去重或聚合，仅将源表全部字段原样抽取入库，并追加加工时间 `etl_time` 与分区标识 `dt`。加工语句如下：

```sql
INSERT INTO ods_user_info_di
SELECT user_info.*, <固定 etl_time>, <分区 dt>
FROM user_info
```

`etl_time` 标记本次抽取的加工时刻，`dt` 用于按日分区存储。当前产出约 2,000 行。

## 依赖与调度

`ods_user_info_di` 的唯一上游为业务库用户基础信息表 `user_info`。调度策略为每日 01:00 开始，在依赖上游全部成功后运行，处理前一天（T-1）的数据，写入对应 `dt` 分区。

## 质量检查

`ods_user_info_di` 入库后须依次通过三项质量检查：主键 / 粒度唯一、关键字段非空、行数与前一天相比波动超过 30% 告警。任一检查未通过，将直接影响以用户基础信息为维度来源的下游加工，使关联用户属性的汇总与报表出现用户缺失或属性错配，导致相关口径失真。
