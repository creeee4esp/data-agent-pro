# 取数需求单 REQ-2025-0103

## 需求

客服部想要 2025-02 单月、各一级品类按日的访客数 `uv`，不加筛选，用来看看哪些品类页面到访的人多，方便安排客服接待的侧重。

## 结论

`dws_traffic_cate1_visit_1d` 是一级品类粒度的按日访问汇总表，拿它来做刚好。字段取 `stat_date`、`category1_id`、`category1_name`、`pv`、`uv`、`stay_seconds`，按 `stat_date` 限定在 2025-02。

这里有个要提醒客服部的点：访客数 `uv` 不能跨行相加。同一个人多天都来、或者在多个品类都逛过，把日度 `uv` 累加会把人重复算，所以别拿它加出整月或全站的去重访客数，要去重得回访问明细重新算。同表的 `pv` 和 `stay_seconds` 倒是可以相加。

这次已经按一次性取数交付客服部了。
