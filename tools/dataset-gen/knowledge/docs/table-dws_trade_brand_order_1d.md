# 表说明：dws_trade_brand_order_1d（DWS-品牌粒度下单汇总（日））

## 概述

`dws_trade_brand_order_1d` 按统计日期和品牌两个维度，对下单行为做日级汇总，当前有 4,213 行。数据来自明细表 `dwd_trade_order_detail_di`，口径是：下单数按订单去重计数，购买件数和已支付金额在品牌维度上求和。需要特别注意，`paid_amount` 只累计已支付订单的明细金额，而 `item_qty` 统计的是全部下单件数（含未支付），两者的分母并不一致，不要拿它们直接算单价。

## 字段

- `stat_date`：统计日期，粒度为天，做趋势查询时按它过滤或分组。
- `brand_name`：品牌名称，与 `stat_date` 共同构成该表的主键粒度，同一天同一品牌只有一行。
- `order_cnt`：下单数，按订单去重后的计数，可以跨天相加得到区间下单总数。
- `item_qty`：购买件数，包含未支付订单的件数，用它估算销量时要清楚口径偏大。
- `paid_amount`：已支付订单的明细金额（元），只统计已支付部分，不要误当成全部下单金额。

## 上下游

数据来源于交易明细表 `dwd_trade_order_detail_di`，按 `order_date` 和 `brand_name` 分组聚合写入，没有登记在册的下游表。需要更粗的汇总时，一般直接基于本表再聚合，而不是去找已有的现成结果表。

## 使用注意

适合做品牌维度的每日下单趋势、按日期区间汇总品牌下单数和已支付金额、以及品牌之间的横向对比。不适合做用户级、SKU 级或品类级的拆解，那些维度请改用对应粒度的 DWS 表。此外，这一家族里还散落着一批带日期的备份表（共 7 张，如 `dws_trade_brand_order_1d_bak_20250102`、`dws_trade_brand_order_1d_bak_20250216`）和 1 张测试表 `test_dws_trade_brand_order_1d`，它们是历史快照或调试产物，数据可能不完整或已过期，统计一律以本表为准，不要混用这些表。
