# 表说明：dws_trade_sku_order_1m（DWS-商品SKU 粒度下单汇总（月））

## 概述

`dws_trade_sku_order_1m` 是 SKU 维度的下单月汇总表，当前 3,181 行。先说清楚一件事，`stat_date` 存的是月初日期，代表整月，不是具体某天，这点别弄混。数据从交易明细 `dwd_trade_order_detail_di` 来，下单数去重、件数和已支付金额求和，口径和日表周表一致，只是聚合到月。

## 字段

- `stat_date`：统计月，取月初日期，按月筛选时用月初日期去匹配。
- `sku_id`：商品SKU ID，`bigint` 类型，和 `stat_date` 一起决定一行，是关联商品维表的主键。
- `order_cnt`：下单数，当月去重后的订单计数，可以跨月相加。
- `item_qty`：购买件数，包含未支付订单，看销量时记得口径偏大。
- `paid_amount`：已支付订单的明细金额（元），只算已支付部分，别当成当月下单总额。

## 上下游

来源是交易明细表 `dwd_trade_order_detail_di`，加工时按月初日期和 `sku_id` 分组聚合写入本表，目前没有下游表。要按品类品牌等更粗维度汇总，走对应维度的表更合适。

## 使用注意

想看 SKU 的月度销量走势、做月度热销榜或月度同比环比，用这张表最省事，一月一个 SKU 一行。要看某天某周就别用它，请改用日表或周表。另外同家族里有一批噪声表：4 张带日期备份（如 `dws_trade_sku_order_1m_bak_20250212`、`dws_trade_sku_order_1m_bak_20250403`）、旧版本 `dws_trade_sku_order_1m_old`、测试表 `test_dws_trade_sku_order_1m`。这些是历史快照、改版遗留或调试产物，数据未必准，做统计时一律认准本表，别图省事取到它们上面。
