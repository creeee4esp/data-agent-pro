# 取数需求单 REQ-2025-0065

## 需求

运营部在 2025-03-16 提了需求 REQ-2025-0065，想要品牌粒度的评价数 `review_cnt`，按周汇总，时间范围 2025-02 至 2025-03，没有筛选条件。他们想看这两个月各品牌的评价量变化。

## 结论

`dws_item_brand_review_1w` 这张表能满足，由商品数据组接的单。按周取 2025-02 至 2025-03 数据，维度用 `stat_date`、`brand_name`，指标给 `review_cnt` 评价数。可加性提醒下：`review_cnt` 和 `good_cnt` 能跨行相加，按品牌或按周汇总直接 SUM 就行；`avg_rating` 是平均评分，不能跨行相加，要整体平均得按评价数加权算。这次已交付一次性取数结果。
