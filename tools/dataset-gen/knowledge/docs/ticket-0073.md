# 取数需求单 REQ-2025-0073

## 需求

财务部希望了解 2025-01 至 2025-03 期间，各一级品类按周的下单表现，核心看下单数 `order_cnt`，不设额外筛选，目的是为季度财务复盘提供品类侧的成交规模参考。

## 结论

`dws_trade_cate1_order_1w` 是一级品类粒度的按周下单汇总表，字段包含 `stat_date`、`category1_id`、`category1_name`、`order_cnt`、`item_qty`、`paid_amount`，覆盖本次需要的全部维度与指标。取数时按 `stat_date` 限定在 2025-01 至 2025-03 的周区间即可。

需要特别说明一个口径问题：下单数 `order_cnt` 是不可跨行相加的指标。如果把多周或多品类的 `order_cnt` 直接相加，会因为同一订单在不同周、不同品类重复计数而虚高，所以这个指标只适合逐行看、按最细粒度比较。相比之下，购买件数 `item_qty` 和已支付明细金额 `paid_amount` 可以放心累加，若财务要的是季度总量，建议优先用这两个可加指标。

本次已按一次性取数交付财务部。
