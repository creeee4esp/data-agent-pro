# 数据事故报告：2025-08-05 dws_trade_user_refund_1d 分区缺失

## 现象

`dws_trade_user_refund_1d`（DWS-买家用户粒度退款汇总（日））在 2025-08-05 被发现分区缺失。从现象上看，当天应生成的分区始终没有落地，买家用户粒度的日度退款汇总出现空档，下游在检索该日数据时直接扑空。整段事故持续 1 小时。

## 原因与影响范围

`dws_trade_user_refund_1d` 分区缺失的根源，经分析可归结到上游当天无数据未告警。上游当天空跑且未触发任何提醒，本表因无数据可算而未能产出分区，这是此类问题的典型链路。就波及面来看，本次事故未影响任何下游表，问题被限制在该表自身。

处理上，物流数据组采取补齐维表后重跑的方式恢复分区。目前数据已完成补数，表恢复可用状态。
