# 取数需求单 REQ-2025-0014

## 需求

财务部于 2025-01-16 提出需求 REQ-2025-0014，希望分析广告投放效果，评估投放的产出与转化。

## 结论

REQ-2025-0014 无法满足。原因在于当前数据仓库没有广告投放数据，缺少投放花费、曝光、点击等记录，因此无法计算投放口径下的效果指标，也无法做投放与成交的归因。作为可替代的分析，建议从现有成交与流量数据切入：用 `dws_trade_channel_pay_1d` 按支付渠道看支付笔数与支付金额的结构变化，用 `dws_traffic_vchannel_visit_1d` 按访问渠道看浏览量与访客数的来源分布，侧面反映各渠道的贡献与趋势。需说明这些是渠道层面的表现，并非投放效果的直接度量。本需求由商品数据组评估并给出替代方案。
