# 取数需求单 REQ-2025-0240

## 需求

财务部在 2025-10-13 提出取数，关注 2025-10 的购买件数（`item_qty`），希望按二级品类粒度、日度口径了解当月各细分品类的件数分布，不设筛选条件。本单编号 REQ-2025-0240，处理人数据平台组。财务部意在按件数观察各二级品类的销售结构。

## 结论

`dws_trade_cate2_order_1d` 即 DWS-二级品类粒度下单汇总（日）支撑本次取数，取 `stat_date`、`category2_id`、`category2_name`、`order_cnt`、`item_qty`、`paid_amount`，报告期 `stat_date` 取 2025-10。

加和方面：`item_qty` 可跨行相加，把各二级品类、各天的 `item_qty` 汇总得到当月件数合计是准确的，`paid_amount` 同样可相加。需要留意 `order_cnt` 不可跨行相加，涉及订单量口径时不要逐行求和。

考虑到财务对该结构有持续关注，本次已交付，并沉淀为固定报表。
