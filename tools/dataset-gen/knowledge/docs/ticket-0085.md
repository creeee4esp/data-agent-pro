# 取数需求单 REQ-2025-0085

## 需求

财务部希望按小时维度分析成交和支付的波动，想看一天内不同时段的高峰低谷，以此评估结算和对账的时段安排。

## 结论

这个需求目前无法满足。原因很直接：公司 DWS 层的汇总表最细只到天粒度，所有汇总表都以 `stat_date` 作为时间口径，没有保留小时字段，也没有小时级的汇总表，因此做不出按小时的结果。

可替代的分析有两种思路。一是退而求其次用日粒度观察，先把工作日和周末、月初月末的差异看清楚，很多波动在日度上已经能体现；二是如果确实需要时段级洞察，这属于要新建数据模型的需求，需要从明细日志重新按小时聚合建表，得单独立项评估排期，不在本次取数范围内。本单据先按不可满足结案。
