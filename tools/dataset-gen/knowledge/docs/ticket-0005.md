# 取数需求单 REQ-2025-0005

## 需求

客服部在 2025-01-03 提了需求 REQ-2025-0005，想要支付渠道粒度的支付金额 `pay_amt`（单位元），按日汇总，时间范围 2025-01，没有筛选条件。主要是想看各支付渠道当月的回款情况。

## 结论

`dws_trade_channel_pay_1d` 这张表能直接用，交易侧的数据由流量数据组处理交付。按日取 2025-01 的数据，维度用 `stat_date`、`pay_channel`，指标给 `pay_amt` 支付金额。可加性上这次比较省心，`pay_cnt` 和 `pay_amt` 都能跨行相加，按渠道或按日汇总直接 SUM 就行，不用担心重复计数。这次已交付一次性取数结果。
