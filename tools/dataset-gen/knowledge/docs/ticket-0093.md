# 取数需求单 REQ-2025-0093

## 需求

财务部希望查看 2025-01 单月各一级品类按周的浏览量 `pv`，不加筛选，意在从流量侧理解年初各品类的热度分布，辅助判断营销费用的投放效率。

## 结论

`dws_traffic_cate1_visit_1w` 是一级品类粒度的按周访问汇总表，字段有 `stat_date`、`category1_id`、`category1_name`、`pv`、`uv`、`stay_seconds`，能直接满足需求。取数时把 `stat_date` 限定在 2025-01 的周区间，按品类输出 `pv`。

从口径上分析，浏览量 `pv` 与总停留秒数 `stay_seconds` 都可跨行相加，把某品类整月各周 `pv` 累加、或把各品类汇成大盘都没问题。但访客数 `uv` 不可相加，同一访客跨周到访会被重复计数，若财务想一并了解去重访客规模，需回到访问明细去重，不能用周度 `uv` 直接求和。

本次已按一次性取数交付财务部。
