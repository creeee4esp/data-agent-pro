# 取数需求单 REQ-2025-0012

## 需求

财务部于 2025-01-14 正式提出取数需求 REQ-2025-0012。需求方请求提供用户粒度已支付订单的明细金额 `paid_amount`（单位元），统计口径为按日汇总，时间范围为 2025-01，不设筛选条件。该数据用于财务侧的用户维度回款核算。

## 结论

`dws_trade_user_order_1d` 经确认为本次取数来源表，由数据平台组负责处理与交付。取数维度采用 `stat_date` 与 `buyer_id`，输出指标为 `paid_amount` 已支付订单的明细金额。关于可加性，特此说明：`paid_amount` 可跨行相加，按用户或按日汇总时可直接求和；`order_cnt` 与 `paid_order_cnt` 不可跨行相加，二者为用户级订单去重计数，跨行相加将造成重复，如需整体口径应回源重新统计。本需求已交付，并附 SQL 供需求方自助复用。
