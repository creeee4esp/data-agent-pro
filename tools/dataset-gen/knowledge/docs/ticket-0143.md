# 取数需求单 REQ-2025-0143

## 需求

市场部在 2025-06-13 提单，想看二级品类维度的购买件数 `item_qty`，按日汇总，时间范围覆盖 2025-03 到 2025-05，不加任何筛选条件。他们打算拿这份数据对比各二级品类在春季这几个月的走量情况，不涉及其他拆分。

## 结论

`dws_trade_cate2_order_1d` 这张表正好满足需求，取数用到 `stat_date`、`category2_id`、`category2_name`、`order_cnt`、`item_qty`、`paid_amount` 这几个字段，按 `stat_date` 过滤 2025-03 至 2025-05 即可。要提醒一下：`item_qty` 和 `paid_amount` 可以跨行直接相加，按月或按品类汇总没问题；但 `order_cnt` 是去重口径，不能跨行累加，想看总下单数得回到明细重算。本次已交付，并附了 SQL 供市场部后续自助复用。
