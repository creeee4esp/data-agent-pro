# 取数需求单 REQ-2025-0261

## 需求

物流部于 2025-11-04 正式提出取数申请，请求提供 2025-08 的购买件数（`item_qty`），统计口径为买家用户粒度下单周度汇总，不设筛选条件。本单编号 REQ-2025-0261，交由交易数据组承办。

## 结论

`dws_trade_user_order_1w` 即 DWS-买家用户粒度下单汇总（周）为本次取数之依据表，取用 `stat_date`、`buyer_id`、`order_cnt`、`item_qty`、`paid_amount`，报告期 `stat_date` 取 2025-08 内各周。

须予说明：`item_qty` 与 `paid_amount` 可跨行相加，将各买家、各周的 `item_qty` 累加以得购买件数合计系属合理。惟 `order_cnt` 不可跨行相加，如涉及下单数口径，不得将各买家或各周的 `order_cnt` 简单求和，以免重复计数。

本次已交付，并附 SQL 供需求方自助复用。
