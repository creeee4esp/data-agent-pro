# 表说明：dws_trade_cate2_order_1m（DWS-二级品类粒度下单汇总（月））

## 概述

`dws_trade_cate2_order_1m` 为二级品类维度的下单月度汇总表，当前共 180 行。该表以统计月与二级品类为粒度对下单行为按月聚合，`stat_date` 存储各月月初日期以标识统计月份。数据源自交易明细表 `dwd_trade_order_detail_di`，统计口径与同家族日表、周表保持一致，仅聚合周期不同。

## 字段

- `stat_date`：统计月，取值为月初日期，代表整月而非某日，按月筛选须以月初日期匹配。
- `category2_id`：二级品类ID，与 `stat_date`、`category2_name` 共同构成行粒度，关联与分组建议优先使用该 ID。
- `category2_name`：二级品类名称，供展示与排序使用，因不同一级品类下可能存在同名二级品类，分组时宜一并带上 ID。
- `order_cnt`：下单数，为当月去重后的订单计数，可按月累加。
- `item_qty`：购买件数，包含未支付订单，统计销量时须注意该口径偏大。
- `paid_amount`：已支付订单的明细金额（元），仅累计已支付部分，不应等同于当月下单总额。

## 上下游

数据来源为交易明细表 `dwd_trade_order_detail_di`，加工时按月初日期、`category2_id` 与 `category2_name` 分组聚合写入本表。当前无登记在册的下游表，如需更高层级汇总，通常直接基于本表再行聚合。

## 使用注意

该表适用于二级品类的月度趋势分析、月度同比环比及品类月度排名。若需日或周粒度数据，应改用对应的日表或周表。该家族含若干噪声表：备份表 `dws_trade_cate2_order_1m_bak` 一张，以及带日期备份 7 张（如 `dws_trade_cate2_order_1m_bak_20250531`、`dws_trade_cate2_order_1m_bak_20250621`）。此类表为历史快照，数据可能不完整或已过期，不得用于统计，一切口径以本表为准。
