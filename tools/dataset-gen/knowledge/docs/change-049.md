# 变更公告：新表上线（dws_trade_user_order_1w）

## 变更说明

`dws_trade_user_order_1w`（DWS-买家用户粒度下单汇总（周））上线啦，做买家用户周度下单分析可以用它。

### 这表能干啥

它从 `dwd_trade_order_detail_di` 加工而来，把买家用户维度的周度下单数据沉淀成一张汇总表。以前要看单个买家的周度下单情况得自己从明细聚合，现在直接查这张就省心多了。

### 生效与影响

从 `2025-04-09` 起正式产出。属于新增表，不动任何现有表。原来自己聚合买家周度下单的同学，建议改接 `dws_trade_user_order_1w`，减少重复加工。

流量数据组发布。
