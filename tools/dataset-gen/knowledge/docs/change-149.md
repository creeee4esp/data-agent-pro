# 变更公告：指标计算规则说明（avg_deliver_hours）

## 变更说明

`avg_deliver_hours` 明确计算规则，由交易数据组发布，2025-12-28 生效。

从口径定义看，平均配送时长只统计已签收的物流单，即未签收的物流单不纳入计算。这样界定的意义在于，只有完成签收的订单才具有完整的配送闭环时长，纳入未签收单会因缺少终点而扭曲平均值。

对使用方的影响在于口径一致性：所有引用 `avg_deliver_hours` 的报表与分析应据此复核。若此前未做签收过滤、将在途或未签收物流单一并纳入，请同步调整为“只统计已签收的物流单”，以免不同口径下的配送时长无法横向比较。此说明不改变底层加工逻辑，历史数据不回刷。
