# 取数需求单 REQ-2025-0294

## 需求

财务部于 2025-12-23 正式提出取数申请，所需指标为 `avg_ship_hours`（平均发货时长（小时）），统计粒度为收货省份发货日汇总，时间范围覆盖 2025-05 至 2025-07，筛选条件为仅限陕西省。

## 结论

`dws_lgs_prov_ship_1d` 系承接本需求之数据表，由流量数据组负责取数并交付。可供使用之字段包括 `stat_date`、`receiver_province`、`ship_cnt`、`signed_cnt`、`avg_ship_hours`，按 `receiver_province` 限定为陕西省后取对应日期区间数据。

需特别说明口径事项：`ship_cnt` 与 `signed_cnt` 为计数类指标，可跨行相加；`avg_ship_hours` 为平均值类指标，不得跨行直接相加，如需汇总多日整体平均发货时长，应回到发货明细按加权方式重新计算。

本需求已交付，并附 SQL 供财务部自助复用。
