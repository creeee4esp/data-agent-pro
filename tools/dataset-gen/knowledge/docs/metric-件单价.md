# 指标说明：件单价（件单价）

## 计算公式

件单价为派生指标，由已支付明细金额与购买件数相除得到。

- 口径：paid_amount / item_qty。
- 可加和：否。比率不能跨行、跨天相加或取平均。
- 更长周期：把 paid_amount 和 item_qty 各自汇总后再相除。

## 取哪张表

件单价需由分子分母现算，不单独存字段。

- 参考表：`dws_trade_cate1_order_1d`，从中取 paid_amount 与 item_qty 相除。
- 要求：分子分母取自同一时间范围、同一维度。

## 来源与历史变化

件单价由已支付明细金额与购买件数派生而来，不独立存储。

- 历史变更：自上线以来未调整计算规则。
- 口径一致，可直接用于跨期趋势比较。
