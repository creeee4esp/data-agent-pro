# 取数需求单 REQ-2025-0298

## 需求

会员中心于 2025-12-28 提出，想要 `pv`（浏览量），按访问渠道粒度的访问日汇总来看，时间范围是 2025-10 至 2025-12，没有额外筛选。

## 结论

`dws_traffic_vchannel_visit_1d` 这张表能满足需求，商品数据组用它出数。表里有 `stat_date`、`channel`、`pv`、`uv`、`stay_seconds` 这几个字段。

要提醒一下口径：`pv` 和 `stay_seconds` 可以跨行相加，跨渠道、跨日期汇总都行；`uv` 不能跨行相加，跨渠道或跨日累加会把同一访客重复计入，需要整体 UV 时得回明细去重。

结果已经作为一次性取数交付给会员中心了。
