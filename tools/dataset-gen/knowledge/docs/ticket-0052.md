# 取数需求单 REQ-2025-0052

## 需求

市场部于 2025-02-28 提出取数需求 REQ-2025-0052，关注仓库粒度的已签收单数 `signed_cnt`，希望按月汇总，时间范围 2025-02，不设筛选条件。分析意图是看当月各仓库的签收履约规模，判断各仓的产出。

## 结论

`dws_lgs_warehouse_ship_1m` 作为来源表支撑这次取数，由物流数据组承接。维度从 `stat_date`、`warehouse_id`、`warehouse_region` 展开，输出指标为 `signed_cnt` 已签收单数。使用上要交代清楚：`ship_cnt` 与 `signed_cnt` 可以跨行相加，按仓库或按月汇总时可直接 SUM；而 `avg_ship_hours` 是平均发货时长，不具备可加性，若要整体平均值必须回到单量层面加权，不能对该列直接求和。本需求已交付一次性取数结果。
