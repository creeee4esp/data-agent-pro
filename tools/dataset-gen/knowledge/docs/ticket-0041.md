# 取数需求单 REQ-2025-0041

## 需求

会员中心在 2025-02-18 提了需求 REQ-2025-0041，想要买家用户粒度的支付笔数 `pay_cnt`，按日汇总，时间范围 2025-01 至 2025-02，没有筛选条件。他们想看这两个月各买家的支付笔数分布。

## 结论

`dws_trade_user_pay_1d` 这张表能满足，由流量数据组接的单。按日取 2025-01 至 2025-02 数据，维度用 `stat_date`、`buyer_id`，指标给 `pay_cnt` 支付笔数。可加性上比较省心，`pay_cnt` 和 `pay_amt` 都能跨行相加，按买家或按日汇总直接 SUM 就行。这次已交付，并沉淀为固定报表。
