# 取数需求单 REQ-2025-0142

## 需求

物流部想要 2025-02 至 2025-04、按商品 SKU 粒度的周度访客数 `uv`，不加筛选，用来看看哪些单品到访的人多、备货和配送可能跟着紧。

## 结论

`dws_traffic_sku_visit_1w` 是商品 SKU 粒度的按周访问汇总表，拿它来做刚好。字段取 `stat_date`、`sku_id`、`pv`、`uv`、`stay_seconds`，按 `stat_date` 卡在 2025-02 到 2025-04 的周区间。

这里得提醒物流部一句：访客数 `uv` 不能跨行相加。同一个人多周看同一个 SKU、或者看了多个 SKU，把周度 `uv` 加起来会把人重复算，所以别拿它累加出整段或多 SKU 的去重访客数，要去重得回访问明细。同表的 `pv`、`stay_seconds` 是可以相加的。
