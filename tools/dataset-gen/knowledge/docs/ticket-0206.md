# 取数需求单 REQ-2025-0206

## 需求

运营部于 2025-08-29 提出的需求，落在访问用户粒度的浏览量 `pv` 上，按月汇总，报告期区间为 2025-04 至 2025-06，不设筛选条件。从沟通看，运营部希望以用户为单位观察二季度的浏览分布，识别高活跃访客群体，为运营动作提供依据。

## 结论

`dws_traffic_visitor_visit_1m` 对应这一诉求，取数落在 `stat_date`、`visitor_id`、`pv`、`uv`、`stay_seconds` 这几个字段上，以 `stat_date` 限定 2025-04 至 2025-06 后按 `visitor_id` 铺开即可。分析时要区分口径：`pv` 与 `stay_seconds` 是可加和指标，跨月或跨用户求和都成立；而 `uv` 是去重访客数，不能跨行累加，若要看一段时间的整体 `uv` 须回源重算。本次已交付一次性取数结果。
