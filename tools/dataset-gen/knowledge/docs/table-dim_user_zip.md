# 表说明：dim_user_zip（DIM-用户会员等级拉链表）

## 概述

`dim_user_zip` 是记录用户会员等级变化的拉链表，属于 DIM 层，表注释为 DIM-用户会员等级拉链表，当前 2,000 行。它由 `ods_user_info_di` 加工，用生效开始和结束日期把每个用户的会员等级切成一段段区间，用来还原任意历史时点的会员等级。最容易误用的地方是：查某个历史日期的等级时，必须用 `start_date` 和 `end_date` 做区间过滤，不能只取一行，否则会取错版本。

## 字段

- `user_id` 是 bigint 的用户ID，一个用户可能对应多行，每行是一个等级生效区间。
- `member_level` 是 tinyint 的会员等级，表示该区间内的等级。
- `start_date` 是 date 的生效开始日期，区间左端点。
- `end_date` 是 date 的生效结束日期，右端点，取值 9999-12-31 表示当前有效，查当前等级就筛 `end_date = '9999-12-31'`。

## 上下游

`dim_user_zip` 的唯一上游是 `ods_user_info_di`，加工时以用户当前等级和注册时间构建生效区间。它当前没有下游表，供需要历史等级口径的分析按需关联。

## 使用注意

`dim_user_zip` 适合还原历史某天的会员等级，比如查 2025-06-01 的等级要用 `start_date <= '2025-06-01' AND end_date >= '2025-06-01'`；查当前等级则筛 `end_date = '9999-12-31'`。它不适合简单按 `user_id` 直接 join，一个用户多行会导致笔数翻倍，关联时务必带上日期区间条件。本家族有备份表 `dim_user_zip_bak`、带日期备份 `dim_user_zip_bak_20250310` 和测试表 `test_dim_user_zip`，均为时点副本或调试产物，不保证完整，统计与关联一律用 `dim_user_zip`。
