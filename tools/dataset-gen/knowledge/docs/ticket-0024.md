# 取数需求单 REQ-2025-0024

## 需求

物流部于 2025-01-27 正式提出取数需求 REQ-2025-0024。需求方请求提供访问渠道粒度的总停留秒数 `stay_seconds`，统计口径为按日汇总，时间范围为 2025-01，不设筛选条件。该数据用于观察各访问渠道的用户停留表现。

## 结论

`dws_traffic_vchannel_visit_1d` 经确认为本次取数来源表，由物流数据组负责处理与交付。取数维度采用 `stat_date` 与 `channel`，输出指标为 `stay_seconds` 总停留秒数。关于可加性，特此说明：`pv` 与 `stay_seconds` 可跨行相加，按访问渠道或按日汇总时可直接求和；`uv` 为去重访客数，不可跨行相加，跨行相加将造成重复计数，如需整体 `uv` 须回源去重。本需求已交付一次性取数结果。
