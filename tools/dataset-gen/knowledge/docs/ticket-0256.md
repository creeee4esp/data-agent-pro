# 取数需求单 REQ-2025-0256

## 需求

管理层在 2025-10-30 提出取数，关注 2025-02 至 2025-04 的下单数（`order_cnt`），希望按品牌粒度、月度口径观察各品牌连续三个月的下单走势，不设筛选条件。本单编号 REQ-2025-0256，处理人流量数据组。管理层想从品牌下单节奏切入，判断季初的增长动能。

## 结论

`dws_trade_brand_order_1m` 即 DWS-品牌粒度下单汇总（月）支撑本次取数，取 `stat_date`、`brand_name`、`order_cnt`、`item_qty`、`paid_amount`，报告期 `stat_date` 覆盖 2025-02 至 2025-04。

分析时有个口径需提醒：`order_cnt` 不可跨行相加，想得到某品牌三个月的下单总量时不要把月度 `order_cnt` 直接相加，否则可能重复计数，建议逐月对比趋势。`item_qty`、`paid_amount` 可跨行相加，适合做区间合计。

考虑到品牌走势需持续跟踪，本次已交付，并沉淀为固定报表。
