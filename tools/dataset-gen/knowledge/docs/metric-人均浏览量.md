# 指标说明：人均浏览量（人均浏览量）

## 计算公式

人均浏览量为派生指标，口径是 pv / uv（uv 不可跨天相加）。分子取浏览量、分母取去重访客数，相除得到平均每个访客看了多少次。它是比率，不可加和。举例：想算某渠道一周的人均浏览量，不能把 7 天的日人均值再平均，而要把当周的 pv 汇总、uv 按一周重新去重后相除；尤其 uv 不可跨天相加，直接累加日 uv 会偏大。

## 取哪张表

人均浏览量需由分子分母现算，不单独存字段。参考表为 `dws_traffic_vchannel_visit_1d`，从中取 pv 与 uv 相除即得当日人均浏览量。举例：要看某访问渠道昨天的人均浏览量，在这张表里取对应渠道的 pv 和 uv 相除；要看一周的，务必把周内 pv 汇总、uv 回明细按周去重后再除，不能用日值堆。

## 来源与历史变化

人均浏览量由浏览量与去重访客数派生而来，不独立存储，分母 uv 不可跨天相加。该指标自上线以来未调整计算规则，口径一致，可直接用于跨期趋势比较。
