# 取数需求单 REQ-2025-0090

## 需求

运营部现提出取数需求，拟获取 2025-01 至 2025-02 期间各商品 SKU 按日的浏览量 `pv`，不附加筛选条件，用于定位高曝光单品。

## 结论

经评估，`dws_traffic_sku_visit_1d` 系商品 SKU 粒度的按日访问汇总表，可满足本次要求。所取字段为 `stat_date`、`sku_id`、`pv`、`uv`、`stay_seconds`，时间范围依 `stat_date` 限定于 2025-01 至 2025-02。

经核验口径，浏览量 `pv` 与总停留秒数 `stay_seconds` 可跨行相加，按 SKU 跨日或按日跨 SKU 汇总均属可行。然访客数 `uv` 不可相加，同一访客多日到访将被重复计数，如需去重访客规模，应回访问明细重新去重，不得将日度 `uv` 简单求和。

本需求已交付，并沉淀为固定报表。
