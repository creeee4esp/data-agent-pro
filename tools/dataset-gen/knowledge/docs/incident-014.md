# 数据事故报告：2025-04-13 dws_trade_user_order_1m 数据重复

## 现象

`dws_trade_user_order_1m`（DWS-买家用户粒度下单汇总（月））于 2025-04-13 经监控发现数据重复。核查确认，该表买家用户粒度的月度下单汇总中存在重复记录，同一用户的下单被重复计入，使汇总数值偏高，属数据重复类事故。事故自发现起持续 3 小时。

## 原因与影响范围

`dws_trade_user_order_1m` 本次重复的根本原因为任务重跑前未清理当天分区，重跑数据与原有分区数据叠加，形成重复。经排查，本次事故未波及任何下游表，影响范围限于该表自身。

处理方面，物流数据组采取清理重复分区后重跑的方式进行修复。截至报告出具，相关数据已完成补数，表内结果恢复正常。
