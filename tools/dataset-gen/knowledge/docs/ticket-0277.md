# 取数需求单 REQ-2025-0277

## 需求

管理层在 2025-11-26 提出取数，关注 2025-10 的已支付订单明细金额（`paid_amount`），希望按会员等级粒度、日度下单口径查看各等级的消费贡献，不设筛选条件。本单编号 REQ-2025-0277，处理人数据平台组。管理层想从会员分层角度看当月不同等级的消费结构。

## 结论

`dws_trade_level_order_1d` 即 DWS-会员等级粒度下单汇总（日）对应本次取数，取 `stat_date`、`member_level`、`order_cnt`、`item_qty`、`paid_amount`，报告期 `stat_date` 取 2025-10。

加和方面：`paid_amount` 可跨行相加，把各会员等级、各天的 `paid_amount` 汇总得到各等级当月消费金额，再横向对比分层结构是准确的，`item_qty` 同样可相加。要注意 `order_cnt` 不可跨行相加，涉及下单数口径不要直接求和。

考虑到会员分层需持续观察，本次已交付，并附 SQL 供需求方自助复用。
