# 取数需求单 REQ-2025-0124

## 需求

市场部需 2025-03 至 2025-04、各会员等级按日的购买件数 `item_qty`，无筛选，用于等级间销量差异的观察。

- 时间范围：2025-03 至 2025-04
- 维度：会员等级
- 核心指标：购买件数 `item_qty`

## 结论

`dws_trade_level_order_1d` 对口，为会员等级粒度的按日下单汇总表。

- 取数字段：`stat_date`、`member_level`、`order_cnt`、`item_qty`、`paid_amount`
- 时间范围：`stat_date` 限定 2025-03 至 2025-04
- 可加：`item_qty`、`paid_amount` 可跨行相加，按等级跨日或跨等级汇总均可
- 注意：`order_cnt` 不可相加，跨行累加会重复计数
- 交付：已交付，并沉淀为固定报表
