# 取数需求单 REQ-2025-0287

## 需求

物流部于 2025-12-14 提出，想要 `pay_cnt`（支付笔数），按收货省份粒度的月度支付汇总来看，时间范围是 2025-12，只看重庆市。

## 结论

`dws_trade_prov_pay_1m` 这张表能满足需求，数据平台组用它来取数。表里有 `stat_date`、`receiver_province`、`pay_cnt`、`pay_amt` 这几个字段，按 `receiver_province` 过滤出重庆市即可。

这张表里的 `pay_cnt` 和 `pay_amt` 都是可以跨行相加的，重庆市单一省份直接取对应行就行，不涉及额外汇总问题。

结果已经作为一次性取数交付给物流部了。
