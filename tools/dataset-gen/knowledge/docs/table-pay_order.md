# 表说明：pay_order（支付流水表）

## 概述

`pay_order` 为 CORE 层的支付流水表，记录订单的支付成功流水，当前共 18,031 行。该表以单笔支付为粒度，一行对应一次支付，可用于支付金额、支付渠道分布等分析。作为交易支付链路的贴源来源，其数据经由业务系统同步而来，用于向下游继续加工。

## 字段

- `pay_id`（bigint）：支付单 ID，单笔支付的唯一标识。
- `order_id`（bigint）：订单 ID，用于关联订单，统计时以该字段对应订单。
- `uid`（bigint）：付款用户 ID，即 `user_info.user_id`，按用户聚合支付时以该字段为准。
- `pay_channel`（varchar(20)）：支付渠道，取值为 alipay-支付宝、wechat-微信、card-银行卡、unionpay-云闪付，按渠道统计应使用对应枚举值。
- `pay_amt`（decimal(12,2)）：支付金额，单位元，等于订单实付金额，汇总支付额以该字段为准。
- `pay_status`（varchar(10)）：支付状态，取值为 success-成功，按成功支付统计时以该状态过滤。
- `pay_time`（datetime）：支付完成时间，按支付日期统计时应采用该字段。

## 上下游

`pay_order` 的数据来自业务系统（在线数据库），同步后进入数据平台。其下游为 ODS 层的 `ods_pay_order_di`，由后者承接并向上层加工。

## 使用注意

`pay_order` 适合用于支付金额汇总、支付渠道分布及按用户或订单的支付分析，不适合用于退款或订单商品明细类统计，相关指标应取对应链路的表。库内存在大量同家族噪声表：备份表 `pay_order_bak`、带日期备份 `pay_order_bak_20250101`、按日拆分的日分表（范围为 `pay_order_20250101 ～ pay_order_20251231`，如 `pay_order_20250101`）、按月拆分的月分表（范围为 `pay_order_202301 ～ pay_order_202512`，如 `pay_order_202301`）以及测试表 `test_pay_order`。上述表分别为历史快照、按期拆分存档或调试用途，其口径与完整性不受保证，不得用于正式统计。正式取数一律以 `pay_order` 为准。
